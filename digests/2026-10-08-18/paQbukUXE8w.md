## خلاصه

شرح ویدیو می‌گوید Next.js 16.4 آمده و Cache Components در Next.js 17 برای همه پیش‌فرض می‌شود. چیزهای تازه را `ensureStatic`، کنترل prefetch، ارتقای ایجنت، بازخورد ایجنت، و بردهای کارایی بدون تنظیم می‌نامد.

پست رسمی ۶ اکتبر همان را دقیق‌تر می‌گوید. Cache Components در Next.js 17 پیش‌فرض می‌شود. از ۱۶٫۴ آن را بهترین انتخاب برای هر اپ Next می‌دانند. اپ تازهٔ `create-next-app` از امروز Cache Components را پیش‌فرض روشن دارد. اپ موجود برای مهاجرت `next upgrade --agent` و Skillهای جدا دارد. دو فلگ مدل: `cacheComponents: true` و `partialPrefetching: true`.

`'use cache'` را نسخهٔ سطح کامپوننت هدر Cache-Control می‌نامند. در مثال داشبورد، خوشامدِ کاربر جاری هر درخواست است و `Projects` با `'use cache'` و `cacheLife('hours')` کش می‌شود. یک صفحه می‌تواند پوستهٔ استاتیک و تکهٔ زمان درخواست را با هم بفرستد، مثل پست بلاگ کنار آواتار کاربر. همان انعطاف هزینه را هم قایم می‌کند: یک کامپوننت داینامیک ویژگی هزینهٔ صفحه را عوض می‌کند.

`ensureStatic = 'navigation'` اگر محتوای داینامیک وارد صفحه شود بیلد را می‌شکند، تا ناوبری آن مسیر در زمان درخواست رندر نشود. مقدارهای شل‌تر `"prefetch"` و `"shell"` هستند. می‌شود آن را روی لی‌اوت، از جمله لی‌اوت ریشه، گذاشت.

برای اینباکس، `prefetch` روی هر `Link` داده و UI کش‌شدهٔ پیام را همین که لینک دیده شد می‌کشد، از جمله تردی که کاربر باز نمی‌کند. `await navigation()` از `next/cache` رندر ترد را تا ناوبری واقعی عقب می‌اندازد. `prefetch()` جداست و محتوای کش‌شده را تا یک prefetch صریح از پوستهٔ اولیه بیرون می‌گذارد.

ارتقای ایجنت: `npx next@canary upgrade --agent=latest`. نسخه را چک می‌کند، ریلیز هدف را برمی‌دارد، راهنما و codemod و گام تأیید را به ایجنت می‌دهد. `experimental.agentUpgrade` پیش‌فرضش `'security'` است. `'latest'` ریلیز تازه‌تر را هم می‌گوید. `false` یادآوری را خاموش می‌کند. روی `next dev` و `next build` سقلمه می‌زند.

بازخورد ایجنت آزمایشی است. برای اپ تازه با تنظیم توصیه‌شدهٔ `create-next-app` روشن است. اپ موجود با `experimental.agentFeedback: true` وارد می‌شود. `next dev` به ایجنت دستور جمع کردن مسئله را می‌دهد. پیش‌نویس در مرورگر باز می‌شود. ایجنت نباید کد منبع و لاگ و راز و جزئیات خاص پروژه را بگذارد. تا Send feedback چیزی فرستاده نمی‌شود. تله‌متری لازم است و در CI اجرا نمی‌شود. صفحهٔ پیکربندی می‌گوید خود گزینه پیش‌فرض خاموش است و اپ تازه آن را در کانفیگ تولیدشده روشن می‌کند. این دو جمله با هم تعارض ندارند.

برای همهٔ اپ‌ها، بدون تنظیم: کش دیسک Turbopack ۲۰ تا ۲۵٪ کوچک‌تر شده، با Zstandard برای داده و LZ4 برای متادیتا. HMR سرور تنبل شده. ران‌تایم Turbopack یک چانک مشترک شده. نام کلاس CSS Module در پروداکشن کوتاه‌تر است. React 19.3 با View Transitions و Fragment Refs پایدار آمده.

کامپایلر React نسخهٔ Rust آزمایشی است. تیم Turbopack می‌گوید تغییر تخصیص حافظه، حافظهٔ کامپایلر را ۳۰٪ و زمان کامپایل را ۱۵٪ کم کرده. روشن کردنش `reactCompiler: true` و `experimental.turbopackRustReactCompiler: true` است. این برد عمومیِ بدون فلگ نیست.

گفتار ویدیو «Next.js» را پی‌درپی «next year» شنواند، دستور را جویده گفت، و برای عقب انداختن ترد اینباکس «await prefetch» گفت. پست رسمی برای آن مثال `await navigation()` دارد و `prefetch()` را API جدا می‌گذارد. عدد ۲۰–۲۵٪ کش دیسک و ۳۰٪ / ۱۵٪ کامپایلر در پست رسمی هست. پست این اجرا نام API و دستور را از پست رسمی می‌گیرد، نه از رونویسی.

## نکته‌های کلیدی

- ۱۷ پیش‌فرض می‌شود. ۱۶٫۴ توصیه می‌کند و اپ تازه را روشن می‌سازد
- `ensureStatic = 'navigation'` بیلد را روی تکهٔ داینامیک می‌شکند
- prefetch اینباکس می‌تواند تردِ باز نشده را هم بکشد. `navigation()` آن را عقب می‌اندازد
- بازخورد ایجنت پیش‌نویس است. تا Send چیزی نمی‌رود
- ۳۰٪ و ۱۵٪ مال کامپایلر Rust آزمایشی است

## چه وارد پست نشد

- جمع‌آوری زبالهٔ دیسک، import داینامیک تنبل، worker thread، و additional roots. در پست نیامد
- ادعای ویدیو که «باید به ایجنت کنترل ارتقا را بدهیم». نظر راوی است
