## خلاصه

ماتیاس جمع‌بندی آخر ۲۰۲۵ از DevTools نسخه‌های ۱۴۲ تا ۱۴۴ است. محور اول، سرور MCP خود DevTools است. پروتکل مدل‌کانتکست به عامل اجازه می‌دهد همان ابزارهای توسعه‌دهنده را از راه یک API صدا بزند، مستقل از این‌که مدل زیرش Gemini باشد یا Claude یا Copilot یا Cursor. بعد از نصب، عامل می‌تواند Chrome محلی را باز کند، صفحه را طی کند، فرم پر کند، اسکرین‌شات بگیرد، و HTML و CSS و کنسول و شبکه را بخواند. وعده این است که راه‌اندازی برای بیش از ۱۵ کلاینت مستند شده.

از Chrome 142 می‌شود درباره کل performance trace با کمک هوش مصنوعی حرف زد، بدون این‌که اول یک بازه را به‌زور به‌عنوان کانتکست انتخاب کنی. ضبط می‌کنی و بعد روی یک insight یا یک activity دقیق می‌شوی. از Chrome 143 اشتراک‌گذاری trace غنی‌تر شده: هنگام export می‌توانی کپی HTML و CSS و JS و source map را هم بچسبانی تا همکارت نام تابع اصلی را ببیند، نه فقط باندل مینیفای. این پیوست اختیاری است.

پنل قدیمی مسدودکردن درخواست به «شرایط درخواست» تغییر نام داده. علاوه بر بلاک الگو، می‌توانی فقط همان درخواست را کند کنی تا بالاخره جواب بدهد. به درد دیدن اثر تصویر و فونت و اسکریپت کند می‌خورد، بدون این‌که کل شبکه را throttle کرده باشی.

در کنسول و Sources، پیشنهاد Gemini از نوع تکمیل است نه تولید کد: کمی تایپ می‌کنی، پیشنهاد می‌آید، Tab می‌زنی. بدون چند کاراکتر زمینه، پیشنهاد معقول نیست. نکته آخر ظاهراً کوچک است و در کار روزمره بزرگ: کشوی DevTools را می‌شود مثل بقیه پنل‌ها چید، مثلاً Elements کنار Sources و Performance کنار Network.

## نکات کلیدی

- DevTools MCP یعنی عامل، Chrome واقعی را بازرسی می‌کند نه این‌که از روی حدس DOM بنویسد.
- چت روی trace از ۱۴۲ کل ضبط را می‌فهمد؛ انتخاب تکه، دقت را بالا می‌برد نه این‌که پیش‌شرط حرف‌زدن باشد.
- trace اشتراکی با سورس‌مپ، دیباگ را از «روی ماشین من کند است» به یک فایل قابل‌ارسال تبدیل می‌کند.
- throttle تک‌درخواست، جای بلاک کامل را وقتی نمی‌گیرد که بخواهی شکست تدریجی را ببینی.
- پیشنهاد کنسول تکمیل است. هنوز باید خودت جمله را شروع کنی.

## برش کوتاه

> عامل می‌تواند همان ابزارهایی را به کار ببرد که تو در DevTools به کار می‌بری. مدل زیرش مهم نیست؛ پروتکل مشترک است.

> می‌توانی یک درخواست را کند کنی بدون این‌که کل شبکه را گروگان بگیری. برای فونت و اسکریپت، همین کافی است که اثرش را ببینی.
