## خلاصه

ویدیو با CLAUDE.md پروژه شروع می‌شود. شش قاعده. آخری می‌گوید هرگز env را ویرایش نکن. اول بپرس. گفتار «Envy» شنید. از بقیهٔ جمله و عنوانِ کار، env است. از Claude Code می‌خواهد سرور توسعه را به پورت تازه ببرد. مدل پورت را پیدا می‌کند، می‌ایستد، و اول می‌پرسد. قاعده کار کرده. نگهبانش خود مدل است و هیچ چیز دیگر.

سه جا برای قاعده می‌شمارد و می‌گوید هر جا ضمانت متفاوتی می‌دهد. یک رله بین Claude Code و API گذاشته تا درخواست واقعی را بخواند.

جای اول پوستر است، همان CLAUDE.md. روی سیم، متن فایل کلمه‌به‌کلمه بالای هر نوبت است. Claude Code آن را در یادداشتی می‌پیچد که می‌گوید این دستورها رفتار پیش‌فرض را عوض می‌کنند و دقیقاً دنبال شوند. فایل خودش ۱۸۲ توکن است. می‌گوید سند پیشنهاد می‌کند زیر ۲۰۰ خط بماند، و باز هم کلمه است. مدل پوستر را می‌خواند، با کار وزن می‌کند، و تصمیم می‌گیرد. این بار خوب تصمیم گرفت. جملهٔ سند را این‌طور نقل می‌کند: Claude این فایل‌ها را زمینه می‌داند و چیزی را اجبار نمی‌کند. ضمانت پوستر این است که همیشه در دید است، نه بیشتر.

سند حافظه که همین اجرا باز شد همین خط را دارد: Claude فایل‌های CLAUDE.md را زمینه می‌داند، نه پیکربندیِ اجباری. برای بستن یک کار، هرچه مدل تصمیم بگیرد، هوک PreToolUse است. در بخش نوشتن دستور هم هدف را زیر ۲۰۰ خط برای هر فایل CLAUDE.md می‌گذارد، چون فایل بلندتر زمینه را می‌خورد و پیروی را کم می‌کند. سقف ۲۰۰ خط یا ۲۵ کیلوبایت که در جدول کنارش است مال بارگذاری auto memory است، نه اندازهٔ همین فایل ۱۸۲ توکنی. این دو را یکی نمی‌کنم.

جای دوم قفسهٔ دفترچه است. اسکیل یک پوشه با یک فایل SKILL.md است. بین دو خط فاصله، نام و شرح است. آن را عطف می‌خواند و پایینش را دفترچه. مثال دفترچه، قدم‌های اضافه کردن فیلد به کاربران است. قبل از استفاده، درخواست فقط عطف را دارد: یک خط، نام و کاربرد، حدود ۵۰ توکن. وقتی می‌خواهد روی هر کاربر فیلد ایمیل باشد، مدل همان اسکیل را برمی‌دارد و درخواست بعدی کل دفترچه را دارد. می‌گوید اسکیل تا لازم نشده تقریباً هیچ هزینه‌ای ندارد و مدل از روی شرح انتخاب می‌کند. شرح را جوری بنویس که خودت کار را همان‌طور بخواهی.

جای سوم اینترلاک است. در Claude Code هوک است، داخل فایل تنظیمات، زیر pre-tool-use. قبل از هر edit یا write یا فرمان شل، اسکریپت اجرا می‌شود. فراخوانی ابزار را روی stdin به شکل JSON می‌گیرد. اگر صدا قرار باشد env را عوض کند، دلیل چاپ می‌کند و با کد ۲ خارج می‌شود. دو یعنی بلوک. همان کار را با هوک روشن تکرار می‌کند. مدل مثل قبل می‌پرسد. این بار او می‌گوید بله. مدل می‌رود سراغ env و صدا قبل از اجرا می‌ایستد. دلیل به‌عنوان نتیجه برمی‌گردد. مدل دو فایل دیگر را عوض می‌کند و همان یک فرمان را می‌سپارد به خودِ او. حتی بله از هوک رد نمی‌شود. روی سیم، قبل از بلوک، خودِ هوک داخل درخواست نیست. مدل اینترلاک را نمی‌بیند. فقط بعد از توقف، دلیل را می‌خواند. Claude Code هوک را دورِ صدای ابزار، هر بار، اجرا می‌کند.

دو نکتهٔ خودش: کد خروج ۱ بلوک نمی‌کند. فقط ۲. اگر اسکریپت نباشد یا گیر کند، صدا رد می‌شود. می‌گوید اینترلاک را قبل از اعتماد تست کن. و مثل سرور MCP ویدیوی قبلی، هوک برنامه‌ای است که با مجوز تو اجرا می‌شود. قبل از گذاشتن در تنظیمات، بخوانش.

جمع‌بندی: قاعده‌ای که تقریباً برای هر کار است و در یک خط جا می‌شود، پوستر. مثالش گرفتن داده با TanStack Query و تست با npm test. رویه‌ای که فقط بعضی کارها لازم دارند، قفسه. مثالش اضافه کردن فیلد کاربر و چک‌لیست ریلیز. چیزی که باید هرگز یا همیشه رخ بدهد، هرچه مدل تصمیم بگیرد، اینترلاک. مثالش هرگز در env ننویس، و بعد از هر ویرایش Prettier را اجرا کن. هر سه را در ریپوی دمو می‌گذارد. لینک آن ریپو در شرحِ خوانده‌شده نبود.

سند هوک که همین اجرا باز شد، همین شکاف را دقیق‌تر می‌نویسد. روی رویدادی که می‌تواند ببندد، کد ۲ می‌بندد حتی اگر JSON روی stdout بگوید `permissionDecision` برابر allow است. برای بیشتر رویدادها، بدون JSON معتبر، کد ۱ خطای غیرمسدود است و کار ادامه پیدا می‌کند، هرچند ۱ کد شکستِ معمول یونیکس است. اگر مسیر اسکریپت نباشد یا قابل‌اجرا نباشد، شل کدی مثل ۱۲۷ می‌دهد و برای بیشتر رویدادها کار ادامه پیدا می‌کند. سند می‌گوید مسیر غلط در settings درِ سیاست را بی‌صدا باز می‌گذارد. timeout جداست: هوک دستوری یا http یا mcp_tool که روی PreToolUse به timeout برسد، خروجی‌اش دور ریخته می‌شود و صدا از مسیر عادی اجازه ادامه پیدا می‌کند. سند صریح می‌گوید به هوکِ گیرکرده به‌عنوان دروازه تکیه نکن. استثنای همان بند، هوک callback در Agent SDK است که timeout آن صدا را می‌بندد. ویدیو این استثنا را نگفت.
