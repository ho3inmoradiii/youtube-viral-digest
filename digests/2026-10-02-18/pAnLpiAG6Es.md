## خلاصه

صحبت ۲ اکتبر ۲۰۲۶ از AI Engineer World's Fair. یان چورن می‌گوید موج «MCP مرده» پروتکل را با پیاده‌سازی ساده‌لوح کلاینت قاطی کرده. مشخصات MCP دربارهٔ طراحی هارنس تقریباً هیچ نمی‌گوید؛ اینکه ابزارها چطور وارد کانتکست شوند کار سازندهٔ ایجنت است.

شکل اول استفاده این بود که همهٔ ابزارهای همهٔ سرورها همان اول ثبت شوند. با حدود ده سرور، نزدیک صد ابزار قبل از هر سؤال داخل کانتکست می‌رفت و به گفتهٔ او گاهی حدود یک‌سوم پنجره، پیش از شروع کار، پر می‌شد. نتیجهٔ ابزار دوباره به کانتکست برمی‌گشت، دقت می‌ریخت و هزینه بالا می‌رفت.

سه درمان را جدا می‌کند. ساب‌ایجنت کانتکست اصلی را خلوت می‌کند ولی توکن را حذف نمی‌کند و دادهٔ حساس را هنوز داخل یک پنجره نگه می‌دارد. کشف تدریجی ابزار، که اواخر پارسال از Anthropic (ابزار جست‌وجوی ابزار در Claude) و بعد Cursor آمد، فقط ابزار لازم را اضافه می‌کند. Code Mode از Cloudflare ابزار را به‌جای تابع، کد می‌بیند. استدلالش این است که صدا زدن ابزار قرارداد مصنوعی است و در دادهٔ آموزشی طبیعی کم بوده، در حالی که مدل‌ها کد و grep را خوب بلدند. پیاده‌سازی Code Mode در کلود را بسته به همان پلتفرم و سخت‌استفاده می‌داند و می‌گوید بیشتر کلاینت‌ها هنوز در همان دورهٔ قدیمی‌اند.

CLI از اول همین رفتار را دارد: کمک را تدریجی می‌خواند، دستور را مثل کد اجرا می‌کند، و شل را از دادهٔ آموزشی می‌شناسد. ضعف CLI این است که جعبهٔ سیاه محلی است؛ برای دسترسی ریموت، استاندارد و تزریق credential مناسب نیست. جمع‌بندی او: MCP برای ریموت و احراز هویت، CLI برای محلی.

mcpc را کلاینت جهانی CLI روی MCP معرفی می‌کند: بدون LLM، پوششی سبک، نصب با npm یا bun، خروجی `--json`، نشست پایدار، credential در keychain سیستم‌عامل، کشف ابزار با grep، تسک ناهمگام، و پشتیبانی x402. در Connector Evals اولیه با Claude Code و Sonnet 5، mcpc و CLI از نظر زمان و هزینه نزدیک بودند؛ MCP خام در یک نمودار سریع‌تر تمام کرد ولی توکن بیشتری خورد و در نمودارهای دیگر ضعیف‌تر بود. خودش این اعداد را هنوز زودرس می‌داند. حرف آخر: CLI بهتر از MCP نیست؛ MCP به‌علاوهٔ CLI بهتر است.

## نکته‌ها

- پر شدن کانتکست باگ هارنس است، نه نقص ذاتی پروتکل.
- ساب‌ایجنت هزینه و نشت دادهٔ حساس را حل نمی‌کند؛ فقط جابه‌جا می‌کند.
- مدل در نوشتن کد از صدا زدن ابزار قوی‌تر است، چون دومی را باید جدا یاد بگیرد.
- ارزیابی را روی خود کانکتور بگذار، نه فقط روی مسابقهٔ ایجنت‌ها.
