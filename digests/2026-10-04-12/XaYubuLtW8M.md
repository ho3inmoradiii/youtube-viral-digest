## خلاصه

ویدیو می‌گوید Anthropic ماد را به Claude Code آورده و این با مهارت و هوک و سرور MCP فرق دارد. آن‌ها بیرون Claude Code زندگی می‌کنند و Claude Code وقتی لازم دارد صدایشان می‌کند. ماد داخل خود نشست است و می‌تواند درست قبل از عمل، آن را عوض کند یا متوقف کند. شکل فنی‌اش پلاگین است، با این فرق که فایل هوک به یک ماژول جاوااسکریپت یا تایپ‌اسکریپت اشاره می‌کند و گام بیلد اضافه ندارد. با پرچم پوشه، Claude Code همان پوشه را تماشا می‌کند و با هر ذخیره ماد را در نشست باز از نو لود می‌کند.

مثال ویدیو: قبل از force push تابع تو صدا می‌شود و سه چیز می‌گیرد. خود رویداد، راه برگشت برای کشیدن روی صفحه یا خواندن فایل یا پرسیدن از تو، و تابع `next`. می‌توانی `next` را صدا بزنی و بگذاری رد شود، دستور را عوض کنی و بعد `next` را صدا بزنی، یا `next` را اصلاً صدا نزنی و خودت جواب بدهی، مثلاً «در این ریپو force push نداریم». می‌گوید ماد می‌تواند ایمیل را روی صفحه پنهان کند در حالی که مدل هنوز آدرس واقعی را می‌بیند. این جملهٔ گفتار است و در مقالهٔ راهنما با همین مثال نیامده، پس وارد پست نشد.

فرق با هوک را این‌طور می‌گوید. هوک یک اسکریپت شل است که یک‌بار برای یک رویداد اجرا می‌شود و می‌رود. ماد یک‌بار لود می‌شود و تا آخر نشست می‌ماند، می‌تواند چیزها را به یاد بسپارد، پنل زنده نشان بدهد، دستور را نگه دارد و بپرسد، و دستور اسلش اضافه کند که بدون صدا کردن مدل کد خودت را اجرا کند. می‌گوید Anthropic خودش بخشی از Claude Code را ماد ساخته و قاب دیف و پشتیبانی ایجنت از این دسته‌اند. پیادهٔ گفتار این‌جا نامفهوم بود. مقالهٔ ۱ اکتبر دقیق است: پشتیبانی AGENTS.md و قاب `/diff` کنار گفتگو ماد هستند و سورس‌شان با تست در ریپوی عمومی `anthropics/claude-code` زیر `mods/` است. پست همان جملهٔ مقاله را می‌آورد.

دموی ویدیو یک شمارندهٔ ابزار است. `/tally` عدد سه را نشان می‌دهد. فایل را در نشست باز ویرایش می‌کند، Claude Code از نو لود می‌کند، و شمارنده صفر می‌شود. دلیلش در گفتار این است که ری‌لود کد را تازه شروع می‌کند و چیزی که باید بماند باید در Claude Code ذخیره شود نه در فایل. مقاله همان نقطه را این‌طور می‌گوید که حالت پایدار در `$.state` می‌ماند. مقاله همچنین می‌گوید از نسخهٔ ۲.۱.۲۸۷ ماد پیش‌فرض روشن است، ماژول سندباکس خودش را دارد و DOM و Node ندارد، و هر دسترسی بیرون از ماژول از `$` رد می‌شود. همان API شامل فایل و فرایند و شبکه است.

سه حرکت در مقاله اسم دارند. Observe یعنی `next` را صدا بزنی و نتیجه را ببینی. Rewrite یعنی رویداد عوض‌شده را به `next` بدهی. Answer یعنی بدون `next` خودت جواب بدهی، مثلاً `{ deny: "…" }`. هوک تنظیمات فرمان شل است و JSON را از stdin و stdout رد می‌کند.

بقیهٔ ویدیو نصب از مارکت‌پلیس، یک نوار برای مدل محلی روی مک‌بوک و دو دستگاه DGX Spark، یک گارد برای `rm -rf`، و یک پرامپت است که ۲۰ نشست آخر را می‌خواند و قبل از ساختن ایده را نشان می‌دهد. این پرامپت را به یک پست در X نسبت می‌دهد و این اجرا آن پست را جدا چک نکرد. هشدار خودش این است که ماد روی ماشین تو اجرا می‌شود و می‌تواند فایل بخواند، برنامه اجرا کند، و به شبکه برود. قبل از نصب ماد غریبه `claude plugin validate` را بزن تا رویدادها و فراخوان‌ها را فهرست کند. اگر هوک شل برای بستن یک چیز کافی است، ماد لازم نیست. مهارت برای پیروی از دستور است. MCP برای رسیدن به سرویس دیگر است. ماد برای چیزی روی صفحهٔ خودت، برای حافظهٔ نشست، یا برای ایستادن و پرسیدن است.

حدس پایانی ویدیو این است که مارکت‌پلیس ماد زیاد می‌شود و بعد اولین مادِ خراب می‌آید. این پیش‌بینی است و وارد پست نشد.
