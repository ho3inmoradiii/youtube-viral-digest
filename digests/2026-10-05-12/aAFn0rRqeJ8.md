## خلاصه

برد تراورسی یک هوک تایمر حدود شصت خط می‌سازد، با state و effect، بدون منطق مخصوص یک پلتفرم. همان فایل، نه ده نسخه، داخل یک ریپو و یک پکیج مشترک می‌رود و ده اپ آن را مصرف می‌کنند. حرف اولش این است که ری‌اکت خودش رندر نمی‌کند. کامپوننت، UI را برای state فعلی توصیف می‌کند و یک رندرر آن را روی یک پلتفرم اعمال می‌کند. روی وب، React DOM همان DOM را عوض می‌کند.

ده اجرای `npm` که در گفتار آمد:

1. `npm run web` روی `localhost:5173`. رندرر React DOM. دایره با SVG و دکمه‌ها همان اکشن‌های هوک را می‌زنند.
2. `npm run electron`. پنجرهٔ دسکتاپ است، ولی رندرر هنوز React DOM است. Electron کرومیوم را جا می‌دهد و API دسکتاپ از پروسهٔ main می‌آید. نسخهٔ الکترون را از `window.host.electron` می‌خواند. بقیه همان هوک است.
3. `npm run mobile`. React Native. رندرر جدا. استایل از `StyleSheet` خود React Native.
4. `npm run terminal`. Ink. `Box` و `Text` و هوک‌هایی مثل `useInput`. شمارش معکوس در ترمینال.
5. `npm run 3`. React Three Fiber. رقم‌ها روی کانوس سه‌بعدی‌اند و دکمه‌ها هنوز React DOM. هوک دست نخورده است.
6. ویدیو با Remotion، خروجی MP4. می‌گوید Remotion رندرر سفارشی به آن معنا نیست. React DOM است و ساعت خودش را ندارد. زمان را از بیرون می‌گیرد.
7. `npm run PDF` با React PDF و `renderToFile`. تایمر زنده داخل PDF ممکن نیست. شش بار همان هوک در یک رندر، هر بار یک لحظه، در یک جدول. یکی از نمونه‌ها روی ۴۵ است.
8. `npm run XR`. همان خانوادهٔ سه بعدی، به‌علاوهٔ ورود به VR و کنترلر. شبیه‌ساز مرورگر را هم نشان می‌دهد.
9. `npm run email` با React Email. کلاینت ایمیل رایج جاوااسکریپت اجرا نمی‌کند، پس شمارش زنده ممکن نیست. مثل PDF یک نمای ثابت می‌سازد، HTML و یک فایل متنی.
10. `npm run nil`. رندرر خروجی را دور می‌ریزد و `null` برمی‌گرداند. هوک داخل Node تیک می‌زند و کنسول لاگ می‌شود. UI نیست. این را برای فرآیند پس‌زمینه یا تست منطق stateful می‌داند، و می‌گوید بیشتر اپ‌ها برای این کار جاوااسکریپت ساده می‌خواهند.

جمع‌بندی خودش، که از دمو مهم‌ترش می‌داند: این ویدیو نمی‌گوید ری‌اکت بهترین است. برای ترمینال یا PDF یا ایمیل یا هر میزبان دیگر، بهترین انتخاب نیست. حرفش این است که از چیزی که خیلی‌ها فکر می‌کنند دورتر می‌رود. بخشی که در هر ده تا بود بخش خسته‌کننده است: state، effect، ترکیب، هوک سفارشی. نه بخشی که دیده می‌شود.

## نکته‌های کلیدی

- یک هوک حدود شصت خط، ده اپ، بدون نسخهٔ جدا برای هر میزبان
- الکترون هنوز React DOM است. Native و Ink و Three رندرر جدا دارند
- PDF و ایمیل لحظهٔ ثابت‌اند، چون جاوااسکریپت زنده ندارند
- `nil` ثابت می‌کند ری‌اکت به UI گره نخورده. خودش می‌گوید برای بیشتر کارها جاوااسکریپت ساده کافی است
- جملهٔ آخر: بهترین انتخاب برای ترمینال و PDF و ایمیل نیست
