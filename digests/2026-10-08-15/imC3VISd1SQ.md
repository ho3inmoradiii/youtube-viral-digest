## خلاصه

شرح اپ را مدیر بسته و لایهٔ رندر فایل می‌داند، نه زمان اجرای ایجنت. API مدل را صدا نمی‌زند، کد خودمختار اجرا نمی‌کند، و مستقیم به مدل پرامپت نمی‌دهد. کاتالوگ بسته‌شده را می‌خواند، قبل از نوشتن فایل شخصا را نشان می‌دهد، متن را به قاعدهٔ Cursor ترجمه می‌کند، و هش مبدأ و هش رندرشده را در دفتر محلی نگه می‌دارد. اگر فایل مدیریت‌شده عوض شود، آن را modified می‌خواند و قبل از بازنویسی مخرب پشتیبان می‌گیرد. دمو هدف سراسری را رد می‌کند و فقط پوشهٔ آزمایش روی دسکتاپ را هدف می‌گیرد. خروجی دمو `.cursor/rules` و یک فایل `.mdc` است.

README همان مرز را تکرار می‌کند: زمان اجرای ایجنت نیست، تله‌متری ندارد، و استفادهٔ اصلی حساب نمی‌خواهد. جدول هدف‌ها دو جور است. Cursor و opencode پروژه‌ای‌اند: `.cursor/rules/*.mdc` و `.opencode/agents/*.md`. Claude Code و Codex و Gemini CLI و GitHub Copilot و Qwen Code و Osaurus روی دامنهٔ user نصب می‌شوند، از جمله `~/.claude/agents/*.md` و `~/.codex/agents/*.toml`. عنوان ویدیو «بدون آلودگی سراسری» است. این برای مسیر Cursor دمو درست است. برای هدف‌های user در جدول README همان جمله سراسری نیست.

دفتر، هش مبدأ و هش رندر و ابزار و مقصد و دامنه و در صورت لزوم مسیر پروژه را ثبت می‌کند. فایل modified قبل از عمل مخرب پشتیبان می‌شود. OAuth دستگاهی گیت‌هاب اختیاری است و توکن در keychain سکو می‌ماند و به فرانت برنمی‌گردد. این با جملهٔ «بدون اعتبار» در شرح یکی نیست، اگر اعتبار را فقط کلید مدل معنی نکنیم. هستهٔ نصب آفلاین است. شبکه برای تازه‌کردن کاتالوگ، OAuth، و به‌روزرسانی روشن است.
