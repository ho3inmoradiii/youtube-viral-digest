# ده به‌روزرسانی وب از Google I/O 2025

- **عنوان:** Top 10 web updates from Google I/O 2025
- **لینک:** https://www.youtube.com/watch?v=GSVe6zguiao
- **کانال:** Chrome for Developers
- **بازدید:** 13442199
- **موضوع:** web platform APIs latest 2026

## خلاصه

خلاصهٔ سریع الکساندریا از Chrome، ده خبر پلتفرم وب در Google I/O 2025 را رد می‌کند. اول کاروسل CSS که در Chrome 135 با چند خط HTML و CSS ساخته می‌شود. پینترست برای کاروسل کلوزآپ نزدیک ۲۰۰۰ خط جاوااسکریپت داشته و بعد از مهاجرت به حدود ۲۰۰ خط CSS رسیده؛ حدود ۹۰ درصد کاهش کد و ۱۵ درصد زمان کمتر برای لود یک پین.

Interest Invoker API در origin trial است: با نشان دادن علاقهٔ کوتاه کاربر (مثلاً hover) پاپ‌اور را اعلانی باز می‌کند و با anchor positioning و popover، منو و تول‌تیپ بدون جاوااسکریپت ممکن می‌شود. APIهای هوش داخل مرورگر هم جلو آمده‌اند: Summarizer، Translator و Language Detector در Chrome پایدار برای وب و اکستنشن؛ Prompt API در اکستنشن پایدار است. Writer و Rewriter هنوز origin trial هستند. مثال دلویت: ترکیب این APIها در آنبوردینگ، پیش‌بینی حدود ۳۰ درصد پیدا کردن سریع‌تر اطلاعات توسط کارمند. ادوبی در اکستنشن Acrobat با Prompt API سند اسکن‌شده را داخل خود مرورگر خلاصه می‌کند. برای دستگاه‌هایی که مدل سمت‌کلاینت را نمی‌کشند، مسیر هیبرید با Gemini و Firebase پیشنهاد شده: پیش‌فرض روی دستگاه، عقب‌نشینی به سرور.

در DevTools، دستیار Gemini روی پنل‌های Elements و Performance و Network و Sources نشسته و در استایل می‌تواند پیشنهاد را مستقیم روی ورک‌اسپیس محلی اعمال کند. پنل Performance هم دادهٔ محلی، Core Web Vitals و سایدبار insight با Lighthouse روی trace دارد. Baseline هم به ابزار رسیده: وضعیت پشتیبانی در VS Code، هشدار ESLint اگر فیچر از هدف baseline جدیدتر باشد، و ترکیب RUM با baseline. مجموعهٔ دادهٔ Web Platform Dashboard برای اولین بار ۱۰۰ درصد نگاشت شده. Credential Manager API هم پسورد، passkey و فدراسیون هویت را به یک UI ورود نزدیک می‌کند. در فروشگاه اکستنشن، لغو ارسال در انتظار ممکن شده است.

## نکات کلیدی

- کاروسل CSS در یک کیس واقعی پینترست، کد را از حدود ۲۰۰۰ خط JS به حدود ۲۰۰ خط CSS رساند.
- Interest Invoker به‌همراه popover و anchor، تعامل را از جاوااسکریپت به پلتفرم برمی‌گرداند.
- مدل داخل Chrome برای خلاصه، ترجمه و تشخیص زبان پایدار شده؛ Writer/Rewriter هنوز آزمایشی‌اند.
- مسیر هیبرید کلاینت/سرور برای دستگاه‌های ضعیف لازم است، نه فرض «همه Nano دارند».
- Baseline حالا در IDE و لینتر قابل‌اجراست، نه فقط جدول caniuse.

## برش کوتاه

> پینترست نزدیک ۲۰۰۰ خط جاوااسکریپت برای کاروسل داشت. با CSS carousel شد حدود ۲۰۰ خط و لود پین ۱۵ درصد سریع‌تر. به میلی‌ثانیه‌هایی فکر کن که پس می‌گیری.
