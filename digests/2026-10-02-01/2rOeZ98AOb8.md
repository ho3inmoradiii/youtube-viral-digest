## خلاصه

ماتیاس آخرین قسمت «تازه‌های DevTools» سال ۲۰۲۵ را برای نسخه‌های ۱۴۲ تا ۱۴۴ مرور می‌کند. محور اول سرور MCP خود DevTools است. Model Context Protocol به عامل هوش مصنوعی اجازه می‌دهد از همان ابزارهایی که کاربر استفاده می‌کند، از راه یک API تخصصی، بهره ببرد. با تکیه بر پروتکلی که گسترده پذیرفته شده، این قابلیت به هر عاملی که MCP را پشتیبانی کند می‌رسد و به مدل زیرین وابسته نیست. گوینده Gemini CLI، Gemini، Cursor، Claude، VS Code و Copilot را نام می‌برد. بعد از راه‌اندازی اولیه، عامل می‌تواند Chrome محلی واقعی را باز کند، بین صفحه‌ها برود، فرم پر کند، اسکرین‌شات بگیرد و با DevTools به HTML و CSS، لاگ کنسول، درخواست شبکه و بقیه نگاه کند. راهنمای نصب برای بیش از ۱۵ کلاینت در لینک ویدیو است.

از Chrome 142 می‌شود دربارهٔ کل performance trace حرف زد بدون اینکه قبلاً زمینه‌ای انتخاب شده باشد: در پنل Performance یک trace ضبط می‌کنید و مستقیم با دستیار هوش مصنوعی گفتگو می‌کنید. وسط گفتگو هم می‌شود insight یا یک activity از trace را به‌عنوان زمینهٔ دقیق‌تر انتخاب کرد. از Chrome 143 به بعد، هنگام خروجی گرفتن از trace می‌شود نسخه‌ای از همهٔ فایل‌های HTML و CSS و JavaScript به‌همراه source map را هم ضمیمه کرد تا همکار بعد از import نام اصلی تابع و فایل منبع را ببیند. این داده اختیاری است.

پنل قدیمی مسدود کردن درخواست شبکه به request conditions تغییر نام داده است. علاوه بر مسدود کردن کامل بر اساس الگو، می‌شود همان درخواست‌ها را فقط کند کرد تا بالاخره موفق شوند. این برای دیدن اثر تصویر، فونت، استایل و اسکریپت کند به کار می‌رود، به‌جای throttle کل شبکه.

در کنسول و پنل Sources، بعد از روشن کردن پیشنهاد کد در تنظیمات AI innovation، Gemini پیشنهاد type-ahead می‌دهد. تایپ می‌کنید، صبر می‌کنید و با Tab می‌پذیرید. گوینده تأکید می‌کند این پیشنهاد تکمیل است نه تولید کد؛ باید خودتان هم چیزی تایپ کنید تا زمینه کافی باشد. نکتهٔ آخر چیدمان کشوی DevTools است: می‌شود پنل‌ها را از حالت چسبیده به پایین به کنار هم برد، مثلاً Elements کنار Sources، Performance کنار Network، و Animations کنار Rendering، تا فقط اطلاعات لازم به شکل دلخواه دیده شود.

## نکات کلیدی

- سرور MCP در DevTools به عامل‌های سازگار با MCP، مستقل از مدل، Chrome محلی و ابزارهای بازرسی را می‌دهد.
- عامل می‌تواند صفحه را باز کند، فرم پر کند، اسکرین‌شات بگیرد و HTML، CSS، کنسول و شبکه را ببیند.
- از Chrome 142 گفتگو دربارهٔ کل trace بدون انتخاب زمینهٔ قبلی ممکن است و وسط چت می‌شود insight یا activity را سنجاق کرد.
- از Chrome 143 خروجی trace می‌تواند HTML و CSS و JavaScript و source map را هم برای دیدن نام اصلی تابع شامل شود؛ این بخش اختیاری است.
- پنل request conditions جایگزین مسدودسازی شبکه شده و می‌تواند درخواست تکی را کند کند، نه فقط کل شبکه را.
- پیشنهاد Gemini در Console و Sources با Tab پذیرفته می‌شود و تولید کد نیست.
- کشوی DevTools را می‌شود کنار هم چید، مثل Elements کنار Sources یا Performance کنار Network.

## برش‌های مهم

- با MCP، DevTools به هر عاملی که این پروتکل را بفهمد می‌رسد و به مدل خاصی بسته نیست.
- گاهی به‌جای حرف زدن با Gemini دربارهٔ کارایی، می‌خواهید یک انسان همان trace را با نام تابع و فایل اصلی ببیند.
- این قابلیت پیشنهاد کد است نه تولید کد؛ باید خودتان هم تایپ کنید تا تکمیل معقولی پیشنهاد شود.
