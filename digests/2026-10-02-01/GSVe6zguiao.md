## خلاصه

الکساندریا، نویسندهٔ فنی ارشد کروم، ده خبر وب Google I/O 2025 را پشت‌سرهم مرور می‌کند. اولین مورد، کاروسل CSS است که در Chrome 135 با چند خط HTML و CSS ساخته می‌شود. او می‌گوید Pinterest برای کاروسل نمای نزدیک نزدیک به ۲۰۰۰ خط جاوااسکریپت داشت و بعد از مهاجرت، کد را حدود ۹۰ درصد کم کرده و به حدود ۲۰۰ خط CSS رسانده، و بارگذاری هر pin هم ۱۵ درصد سریع‌تر شده است.

در origin trial، Interest Invoker API آمده است. این API آزمایشی اجازه می‌دهد popover را به‌صورت اعلانی وقتی علاقهٔ کاربر برای مدت کوتاهی فعال است عوض کنید. ترکیب آن با anchor positioning و popover، رابط تعاملی را بدون جاوااسکریپت ممکن می‌کند.

بخش بزرگ ویدیو APIهای هوش مصنوعی داخل مرورگر است. Summarizer، Translator و Language Detector در Chrome Stable برای وب‌اپ و افزونه در دسترس‌اند و Prompt API هم در افزونه‌های کروم پایدار شده است. Writer و Rewriter، که گوینده آن‌ها را ترجیح می‌دهد، در origin trial هستند: Writer برای شروع پیش‌نویس و Rewriter برای نسخه‌های مختلف و تنظیم لحن. Deloitte این APIها را روی پلتفرم مهندسی خود برای آنبوردینگ و ناوبری آزمایش کرده و پیش‌بینی شده کارکنان حدود ۳۰ درصد سریع‌تر به چیزی که لازم دارند برسند. قابلیت چندوجهی Prompt API هم در افزونهٔ Acrobat ادوبی برای خلاصهٔ سند اسکن‌شده، همان داخل مرورگر، آزمایش شده است. برای دستگاه‌هایی که هوش مصنوعی سمت کلاینت را اجرا نمی‌کنند، همکاری با Gemini و Firebase تجربهٔ ترکیبی می‌سازد: تا جایی که ممکن است Gemini Nano و APIهای داخلی، و در غیر این صورت بازگشت به سرور، از طریق Firebase یا Gemini Developer API.

در DevTools می‌شود در پنل‌های Elements، Performance، Network و Sources با Gemini دربارهٔ زمینهٔ صفحه حرف زد و پیشنهاد استایل را مستقیم روی workspace محلی اعمال کرد. در Performance هم دادهٔ محلی، Core Web Vitals و نوار کناری insights که Lighthouse را به trace می‌آورد در کنار دستیار هوش مصنوعی آمده‌اند. Baseline به VS Code، ESLint و RUM Vision وصل شده و در web platform dashboard مجموعهٔ ویژگی‌های وب برای اولین بار ۱۰۰ درصد نگاشت شده تا وضعیت Baseline هر ویژگی، از اولین عرضه تا پشتیبانی هم‌زمان در مرورگرهای اصلی، دیده شود.

آزمایش توسعه‌دهنده برای بهبود Credential Manager API روی وب هم معرفی می‌شود: درخواست credential و نمایش رمز، passkey و identity federation در یک رابط. در پایان، برای انتشار افزونه در Chrome Web Store امکان لغو ارسالِ در انتظار اضافه شده است.

## نکات کلیدی

- کاروسل CSS در Chrome 135؛ مثال Pinterest: از حدود ۲۰۰۰ خط جاوااسکریپت به حدود ۲۰۰ خط CSS و ۱۵ درصد بارگذاری سریع‌تر pin.
- Interest Invoker API در origin trial، همراه anchor positioning و popover، بدون جاوااسکریپت.
- Summarizer، Translator و Language Detector در Chrome Stable؛ Prompt API پایدار در افزونه‌ها؛ Writer و Rewriter در origin trial.
- Deloitte و افزونهٔ Acrobat ادوبی به‌عنوان آزمایش‌های واقعی این APIها نام برده می‌شوند؛ مسیر ترکیبی با Firebase و Gemini برای دستگاه‌های ضعیف‌تر.
- دستیار Gemini در چهار پنل DevTools، با اعمال پیشنهاد استایل روی workspace و insights مربوط به Lighthouse در trace.
- Baseline در VS Code، ESLint و RUM Vision، به‌علاوه نگاشت کامل ویژگی‌ها در web platform dashboard.
- آزمایش Credential Manager برای یک UI واحد از رمز، passkey و فدراسیون هویت، و امکان لغو submission در انتظار در فروشگاه افزونه.

## برش‌های مهم

- بعد از کاروسل CSS، کد کاروسل Pinterest حدود ۹۰ درصد کمتر شده و بارگذاری pin حدود ۱۵ درصد زمان کمتری می‌گیرد.
- Writer برای جرقهٔ پیش‌نویس اول است و Rewriter برای امتحان نسخه‌ها و تنظیم لحن.
- وقتی این مسیر کامل شود، رمز و passkey و ورود فدراسیونی در یک جا نشان داده می‌شوند تا معلوم باشد آخرین بار چطور وارد شده‌اید.
