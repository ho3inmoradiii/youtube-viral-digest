## خلاصه

ویدیوی رسمی Cursor ده نکته برای کار با ایجنت را روی وب‌سایت شخصی سازنده نشان می‌دهد. نکتهٔ اول Plan Mode است: چت جدید با Command N، بعد Shift Tab تا حالت برنامه عوض شود. ایجنت کدبیس را می‌خواند و برای قابلیت تازه برنامه می‌سازد. مثال، صفحهٔ هنرمندان برتر اسپاتیفای است؛ اسپاتیفای از قبل برای آهنگ آخرِ صفحهٔ اصلی وصل شده. ایجنت پیاده‌سازی فعلی را می‌خواند و سؤال می‌پرسد. مسیر `/music`، ده هنرمند برتر، دو بازهٔ all time و سه ماه اخیر، و برای نمایش «بهترین قضاوت خودت». برنامه در یک فایل مارک‌داون با کامپوننت و فایل و to-do نوشته می‌شود. سازنده یک جملهٔ معرفی سلیقهٔ موسیقی را از برنامه حذف می‌کند و Build می‌زند. مدل Claude 4.5 Sonnet است. بار اول صفحه خطای دسترسی می‌دهد؛ توکن اسپاتیفای باید دوباره مجوز بگیرد. خطا را در چت می‌چسباند و بعد از آن فهرست هنرمندان بالا می‌آید.

نکتهٔ دوم منوی زمینه با `@` است، مخصوصاً `@branch`. اول با Command Shift P شاخهٔ `top-artists` را می‌سازد و از ایجنت می‌خواهد تغییرات را مرور کند. همان منو فایل، پوشه، مستندات عمومی، چت‌های قبلی و خطای لینتر را هم دارد. مرور کدِ تولیدشده یک اختلاف در زمان‌های کش را پیدا می‌کند. نکتهٔ سوم دستور سفارشی است: پوشهٔ commands داخل پوشهٔ Cursor و یک مارک‌داون به نام PR. پرامپت می‌گوید PR با عنوان توصیفی بساز، همیشه GitHub CLI را به کار ببر، و اگر هنوز کامیت نشده اول کامیت کن. با `/PR` ایجنت وضعیت گیت را می‌بیند و لینک پول‌ریکوئست را برمی‌گرداند.

نکتهٔ چهارم چسباندن تصویر است. از ایجنت می‌خواهد صفحهٔ هنرمندان به یک تصویر سبک Spotify Wrapped نزدیک شود و عکس هنرمند داشته باشد. به شوخی می‌گوید لطفاً و ممنون علمی نیست ولی حس می‌کند مدل بهتر جواب می‌دهد، با این هزینه که انرژی دیتاسنتر بیشتر می‌سوزد. ایجنت دریافت تصویر، کامپوننت لیست و پیکربندی URL راه دور را عوض می‌کند. نتیجه عددهای درشت و عکس دارد و نقطهٔ شروع قابل ویرایش است. نکتهٔ پنجم تکثیر چت از منوی سه‌نقطه است تا زمینه بماند و مسیر دیگری امتحان شود. ترجیح خودش کمترین توکن ممکن است و شروع از صفر هم معتبر است. نکتهٔ ششم عقربهٔ پنجرهٔ زمینه است: برای پنجرهٔ ۲۰۰ هزار توکنی Claude Sonnet 4.5 حدود ۱۲ درصد پر شده. دستور `/summarize` گفت‌وگو را فشرده می‌کند و باید عمدی استفاده شود. نکتهٔ هفتم: در تنظیمات، خلاصهٔ مصرف را از auto به always ببرید تا همیشه پایین صفحه باشد. در ویدیو ۳۸ درصد سقف مصرف رفته و زمان ریست هم دیده می‌شود.

نکتهٔ هشتم میانبر است: Command I پنجرهٔ ایجنت را باز می‌کند و Command Slash مدل را عوض می‌کند، مثلاً بین GPT-5 High Fast و Claude 4.5 Sonnet. نکتهٔ نهم شروع مکالمهٔ تازه برای قابلیت تازه است. تازه‌کارها همان چت را با قابلیت پشت قابلیت ادامه می‌دهند تا به سقف زمینه بخورند و کیفیت مدل پایین بیاید. چت عکس هنرمندان حدود ۱۲ درصد زمینه مصرف کرده بود. چت جدید با Command N. نکتهٔ دهم برگشت به checkpoint است. عدد رتبه‌ها را کوچک‌تر می‌کند، بعد به نقطهٔ قبل برمی‌گردد و تغییرات تا آن نقطه را دور می‌ریزد و عددهای درشت برمی‌گردند. می‌گوید این کنار گیت لازم است، چون گیت تغییر را پایدارتر نگه می‌دارد.

دور تند پایانی: صدای اتمام و نوتیفیکیشن سیستم وقتی کار تمام شد یا دستوری اجازه می‌خواهد. می‌شود از ایجنت نمودار Mermaid خواست؛ نمودار جریان اسپاتیفای از کاربر تا اپ و API، جریان OAuth و دست‌به‌دست شدن access token و refresh token را نشان می‌دهد. آخر، چیدمان جدید ایجنت در بتا: ایجنت‌ها در نوار چپ، گفت‌وگو وسط، diff راست، با اتصال به مرورگر برای لاگ شبکه و DOM و ترمینال.

## نکات کلیدی

- Plan Mode با Shift Tab کد را می‌خواند، سؤال می‌پرسد و برنامهٔ مارک‌داون با to-do می‌سازد؛ Build همان را با مدل انتخابی پیاده می‌کند.
- در دمو، Claude 4.5 Sonnet صفحهٔ ده هنرمند برتر را ساخت ولی تا مجوز تازهٔ توکن اسپاتیفای خطا می‌داد.
- `@` فایل، پوشه، مستندات، چت قبلی، لینتر و شاخه را به زمینه می‌آورد. `@branch` اختلاف زمان کش را پیدا کرد.
- دستورهای سفارشی فایل مارک‌داون در پوشهٔ commands هستند. نمونهٔ `/PR` با GitHub CLI اول کامیت و بعد پول‌ریکوئست می‌سازد.
- تصویر را می‌شود چسباند. تکثیر چت زمینه را نگه می‌دارد، ولی توصیه این است که زمینه کوچک بماند.
- عقربهٔ زمینه برای Sonnet 4.5 روی ۲۰۰ هزار توکن است. `/summarize` فشرده می‌کند. مصرف را می‌شود همیشه نشان داد؛ در ویدیو ۳۸ درصد سقف رفته بود.
- چت تازه برای کار تازه، checkpoint برای برگشت، و گیت برای ماندگاری. چیدمان بتا ایجنت‌ها، گفت‌وگو و diff را جدا می‌کند و به مرورگر وصل می‌شود.

## برش‌های مهم

- Plan Mode کدبیس را نگاه می‌کند و به‌جای پریدن مستقیم به پیاده‌سازی، اول یک برنامهٔ قابل ویرایش می‌سازد.
- هرچه گفت‌وگو را با قابلیت پشت قابلیت ادامه بدهید، کیفیت مدل با پر شدن زمینه پایین می‌آید؛ برای کار جدید چت جدید بسازید.
- برگشت به checkpoint تغییر را دور می‌ریزد، ولی گیت هنوز جای ماندگار نگه داشتن همان تغییرهاست.
