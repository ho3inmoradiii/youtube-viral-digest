# Stop Prompting Claude. Start Loop Engineering.

- **عنوان:** Stop Prompting Claude. Start Loop Engineering.
- **لینک:** https://www.youtube.com/watch?v=YAS4ojuhbW4
- **کانال:** Austin Marchese
- **بازدید:** ۱۱۷٬۰۳۵ (طبق متادیتای جستجوی yt-dlp)
- **مدت:** حدود ۱۲ دقیقه
- **موضوع:** prompt engineering tricks for coding agents

## خلاصه

محور ویدیو نقل بوریس چرنی، سازنده Claude Code، است: دیگر به Claude پرامپت نمی‌دهد؛ حلقه می‌نویسد و حلقه‌ها خودشان Claude را صدا می‌زنند. پرامپت یک بار اجرا می‌شود و می‌ایستد. حلقه تا رسیدن به یک تعریف مشخص از «تمام» دوباره اجرا می‌شود.

چهار شرط قبل از ساختن حلقه: کار تکرار شود (کار یک‌باره همان پرامپت است)، تعریف تمام روشن باشد، هزینه توکن را بپذیری، و ابزار لازم برای انجام و راستی‌آزمایی موجود باشد. مثلاً اگر هدف سایت زنده زیر دو ثانیه است، عامل باید بتواند همان دامنه را بزند و زمان را اندازه بگیرد.

چهار بلوک ساخت: ماشه (`/loop` محلی که با بستن لپ‌تاپ می‌میرد، `/schedule` ابری، یا یک skill ارکستر)، skillهای اجرایی که از قبل امتحان شده‌اند نه پرامپت شانسی، هدف به‌اضافه راستی‌آزمایی، و خروجی به‌اضافه حافظه. جمله نقل‌شده: عامل فراموش می‌کند، ریپو نه؛ یک فایل مارک‌داون برای یادداشت بس است. برای کار غیرعددی باید پل ساخت، مثلاً skill بازبینی که فقط «تأیید» یا «رد» برمی‌گرداند، یا چند skill (لحن، فکت، بازبینی ایمیل) که پیش‌نویس را قبول کنند. راستی‌آزمایی را ترجیحاً عامل دیگری ببیند تا تعصب همان نویسنده کم شود.

حالت تمرین: چند اجرای اول، حلقه سر هر گام بایستد تا تو تأیید کنی، بعد حالت تمرین خاموش شود. اگر هدف کمّی نیست، حلقه را روی ایستگاه‌های تصمیم بشکن؛ مثل کارآموز که برای جشن باید تاریخ و مکان و تم را جدا تأیید کند نه اینکه کل مهمانی را یک‌جا حدس بزند.

## نکات کلیدی

- حلقه پرامپت تکراری تا شرط تمام است، نه پرامپت بلندتر.
- بدون تعریف تمام و بدون ابزار سنجش، حلقه توکن می‌سوزاند.
- skill اجرایی باید قبلاً در کار دستی جواب داده باشد.
- حافظه خارج از context، حتی یک مارک‌داون، جلوی تکرار همان خطا را می‌گیرد.
- کار مبهم را با خروجی بله/خیر یا نمره قابل سنجش کن.
- اجرای اول را قفل تأیید انسانی بگذار.
- نقطه تصمیم غلط را پیدا کن؛ اگر آنجا را خودکار کنی بقیه حلقه پرت می‌شود.

## برش کوتاه

> بوریس چرنی می‌گوید کارش دیگر پرامپت دادن نیست؛ نوشتن حلقه است. حلقه بدون تعریف تمام، کارآموزِ بی‌ایستگاه است: توکن خرج می‌کند و جهت را خودش انتخاب می‌کند.
