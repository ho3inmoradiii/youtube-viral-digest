# Browser APIs Just Killed Off Your JavaScript Dependencies

- **عنوان:** Browser APIs Just Killed Off Your JavaScript Dependencies
- **لینک:** https://www.youtube.com/watch?v=jHRHV1MNR5s
- **کانال:** Pixel Grid UI
- **بازدید:** ۴٬۸۵۸ (طبق متادیتای جستجوی yt-dlp)
- **مدت:** حدود ۷ دقیقه
- **موضوع:** web platform APIs latest 2026

## خلاصه

ویدیو با یک عدد شروع می‌کند: ۳۲۲ کیلوبایت، حجم minify و gzip شانزده کتابخانه رایج UI که شاید بشود از پروژه بعدی حذف کرد. حرف اصلی این است که سال‌ها جاوااسکریپت چسب سوراخ‌های پلتفرم بوده و حالا خود پلتفرم همان کار را با یک خط CSS یا چند صفت HTML می‌کند. اسم این انتخاب را اصل کمترین قدرت می‌گذارد: ضدجاوااسکریپت نیست، یعنی ساده‌ترین ابزار کافی را بردار.

مثال ملموس تولتیپ است. راه قدیمی حدود ۶۰ خط برای hover و focus و blur و state. راه تازه حدود ۱۰ خط HTML با Popover API: یک id و صفت `popover`، دکمه با `popovertarget`، و استایل CSS. بستن با کلیک بیرون، Escape، و دسترس‌پذیری را مرورگر انجام می‌دهد نه یک میکرومنیجر JS.

همین جابه‌جایی را برای بقیه الگوها هم می‌شمارد. Container query به‌جای ResizeObserver، اسکرول رانده‌شده با CSS به‌جای GSAP روی main thread، View Transitions برای گذار صفحه، و `<dialog>` به‌جای کتابخانه‌ای مثل Radix فقط برای focus trap و backdrop. اسکرول CSS روی نخ compositor می‌ماند و شنونده JS هر فریم نخ اصلی را اشغال می‌کند. نتیجه را مستقیم به Core Web Vitals وصل می‌کند: INP بهتر چون نخ اصلی آزاد است، LCP بهتر چون JS کمتری رندر را سد می‌کند، CLS کمتر وقتی خود مرورگر چیدمان را دارد. به پروژه HTMX هم اشاره می‌کند که با تکیه بر پلتفرم ۹۶ درصد وابستگی‌ها را کم کرده. پیشنهاد عملی: یک تولتیپ یا مودال یا آکاردئون را با پلتفرم بساز و ببین چه چیزی از package.json پاک می‌شود.

## نکات کلیدی

- ۳۲۲KB برای شانزده کتابخانه UI، مقیاس وابستگی پنهان است نه یک باگ منفرد.
- Popover API تولتیپ را از حدود ۶۰ خط JS به حدود ۱۰ خط HTML declarative می‌برد.
- dialog بومی focus trap، پس‌زمینه، و بستن با Escape را بدون کتابخانه می‌دهد.
- انیمیشن اسکرول CSS کار را از main thread به compositor می‌برد؛ شنونده JS هر فریم هزینه INP است.
- LCP و CLS هم از کم شدن JS مسدودکننده و چیدمان دیرهنگام سود می‌برند.
- شروع عملی: یک الگوی UI را بومی کن و وابستگی همان الگو را حذف کن، نه شعار «بدون فریم‌ورک».

## برش کوتاه

> جاوااسکریپت سال‌ها چسب سوراخ وب بود. Popover و dialog و container query یعنی مرورگر همان کار را تحویل گرفته. هر بار که این کار را به یک پکیج می‌سپاری، هم بایت اضافه می‌خری هم میلی‌ثانیه INP.
