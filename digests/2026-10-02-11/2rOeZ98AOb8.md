## خلاصه

ماتیاس سه قابلیت کروم ۱۴۲ تا ۱۴۴ را دور ابزار روزمره فرانت جمع می‌کند. اول، سرور MCP خود DevTools. پروتکل واحد باعث می‌شود عامل‌هایی مثل Gemini CLI، Cursor، Claude، VS Code و Copilot همان ابزارهای تو را داشته باشند: مرورگر محلی، پر کردن فرم، اسکرین‌شات، بازرسی HTML و CSS، کنسول و شبکه. راه‌اندازی برای بیش از پانزده کلاینت مستند شده است.

دوم، صحبت با کل performance trace بدون انتخاب قبلی context. از پنل Performance ضبط می‌کنی و در چت می‌پرسی؛ وسط حرف می‌توانی یک insight یا activity را به‌عنوان context دقیق‌تر بچسبانی. از کروم ۱۴۳ موقع export تریس می‌توانی کپی HTML و CSS و JS و source map را هم بگذاری تا همکارت نام تابع اصلی را ببیند، نه فقط باندل minify. این داده اختیاری است.

سوم، به‌جای بلاک کامل شبکه، شرایط درخواست: یک درخواست خاص را throttle کنی تا اثر فونت یا اسکریپت کند را ببینی، بدون خواباندن کل شبکه. پیشنهاد کد Gemini در Console و Sources از نوع تکمیل است نه تولید؛ باید خودت بخشی را تایپ کنی و Tab بزنی. در آخر، کشوی DevTools را می‌شود مثل پنل‌ها چید تا مثلاً Elements کنار Sources بنشیند.

## نکات کلیدی

- DevTools MCP یعنی عامل کد همان Chrome محلی را برای DOM، شبکه و کنسول دارد، مستقل از مدل.
- چت روی تریس کامل شده؛ context را وسط مکالمه با انتخاب insight تنگ‌تر می‌کنی.
- اشتراک تریس می‌تواند سورس و source map را هم ببرد تا دیباگ عملکرد تیمی شود.
- Throttle تک‌درخواست جای بلاک همه‌یا هیچ را برای شبیه‌سازی منبع کند گرفته است.
- پیشنهاد Gemini در کنسول تکمیل خط است؛ جای فکر کردن را نمی‌گیرد.
- چیدمان کشو را با کاری که داری جفت کن، نه با چیدمان پیش‌فرض.

## برش کوتاه

> عامل تو از این به بعد لازم نیست کور باشد. سرور MCP دوابزار همان Chrome را به Cursor و Claude و Copilot می‌دهد: صفحه، شبکه، کنسول. تریس را هم می‌توانی با سورس اصلی برای همکارت بفرستی، نه فقط یک فایل minify.
