## خلاصه

ویدیو رسمی Cursor ده عادت کار با Agent را روی سایت شخصی و یکپارچه‌سازی Spotify نشان می‌دهد. اول Plan Mode با Shift+Tab: عامل کد را می‌خواند، سؤال شفاف‌کننده می‌پرسد (مسیر صفحه، بازه زمانی، تعداد هنرمند)، طرح را در مارک‌داون با فایل‌ها و to-do می‌نویسد، و بعد Build با مدل انتخابی (اینجا Claude 4.5 Sonnet) اجرا می‌کند. بار اول صفحه به‌خاطر permission توکن Spotify خراب شد؛ چسباندن همان خطا کافی بود تا درست شود.

دوم، منوی @ از جمله @branch برای ریویو تغییرات همان شاخه، به‌اضافه فایل و پوشه و داک و چت قبلی و خطای لینتر. سوم، دستور سفارشی: مارک‌داون داخل `.cursor/commands` مثل `/PR` که اگر کامیت نشده اول کامیت کند و با GitHub CLI پول‌ریکوئست بسازد. چهارم، چسباندن تصویر و خواستن شباهت به Spotify Wrapped؛ مدل داده تصویر هنرمند و next.config را هم دست می‌زند. پنجم، duplicate کردن چت برای امتحان مسیر دیگر بدون از دست دادن context، هرچند توصیه می‌کند context را کوچک نگه دار. ششم، عقربه context پنجره ۲۰۰ هزارتایی و دستور summarize برای فشرده‌کردن عمدی، نه از سر عادت. هفتم، Usage summary را از auto به always بگذار تا درصد سقف و زمان ریست دیده شود. هشتم، میانبر Command+I برای Agent و Command+Slash برای عوض کردن مدل. نهم، برای هر فیچر چت تازه؛ ادامه دادن یک نخ تا سقف context کیفیت را می‌خورد و Command+N چت جدید است. دهم، برگشت به checkpoint و دور ریختن تغییر تا آن نقطه، با این تذکر که Git هنوز جای ثبت پایدار است.

دور سریع آخر: صدای اتمام، نوتیفیکیشن سیستم، نمودار Mermaid از فلوی OAuth، و چیدمان بتای Agent با فهرست عامل‌ها، گفت‌وگو در وسط، و diff کنار صفحه به‌اضافه مرورگر و ترمینال.

## نکات کلیدی

- Plan Mode قبل از Build سؤال و طرح فایل‌محور می‌سازد؛ اجرای کور گران‌تر است.
- خطای واقعی را برگردان به چت؛ در دمو مجوز Spotify همین‌طور حل شد.
- @branch و دستور مارک‌داونی مثل /PR کار تکراری را از حافظه کوتاه تو خارج می‌کند.
- تصویر مرجع برای UI مؤثر است، ولی خروجی نقطه شروع است نه تحویل.
- context را با چت تازه کوچک کن؛ summarize ابزار عمدی است نه جاروبرقی.
- checkpoint جای Git نیست؛ هر دو را نگه دار.
- سقف مصرف را همیشه ببین اگر هزینه برایت مهم است.

## برش کوتاه

> یک چت را برای پنج فیچر ادامه نده. پنجره که پر شود مدل فراموش‌کار و شلخته می‌شود. فیچر جدید، چت جدید. و اگر طرح را دیدی و بعد Build کردی، باز هم خطا را بخوان؛ تمام شدن Agent به معنی کار کردن صفحه نیست.
