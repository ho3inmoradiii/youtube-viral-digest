# Applications instead of libraries: Micro frontends through module federation

- **عنوان:** [VDZ22] Applications instead of libraries: Micro frontends implemented through module federation
- **لینک:** https://www.youtube.com/watch?v=Ctel5SolOHw
- **کانال:** Devoxx
- **بازدید:** ۱٬۲۸۳
- **موضوع:** Micro Frontends production case study / Module Federation vs iframe microfrontends

## خلاصه

ماریو، مهندس ساکن آلمان، سه محور را روی تجربه Wayfair و پورتال تأمین‌کنندگان (Partner Home) می‌چیند. فروشگاه روبه‌مشتری دیده می‌شود؛ Partner Home جایی است که تأمین‌کننده موجودی را بارگذاری می‌کند و فروش را می‌بیند، با کاربر کمتر و درد سازمانی بیشتر. سند داخلی‌اش از روز اول عنوان «اپلیکیشن به‌جای کتابخانه» داشته. مسئله اول توزیع خود اپ‌های فرانت است، نه استخراج یک کامپوننت مشترک. همان فشار آن‌ها را به میکروفرانت رساند. محور دوم اتخاذ Module Federation است. محور سوم این است که MVP با تولید فرق دارد.

در تولید، remoteEntry.js فقط یک فایل جاوااسکریپت است و کش را همان‌جا کنترل می‌کنی. اگر روی CDN باشد، باطل کردن کش شبیه بقیه assetهاست. راه‌حل جادویی جدا لازم نبود؛ همان ابزارهای کش موجود کافی بود، چون مشکلات بزرگ‌تری برای حل داشتند. اگر مصرف‌کننده باید با چند نسخه کار کند، سازگاری عقب‌رو همچنان قانون است. شکستن قرارداد یعنی یا بارگذاری اجباری ماژول جدید، یا صبر برای release مصرف‌کننده‌ها، یا یک انتشار دو مرحله‌ای.

نکته آرام ویدیو این است: فدریشن مشکل نسخه‌گذاری را حذف نمی‌کند. فقط محل آن را از npm به یک فایل مانیفست روی CDN منتقل می‌کند.

## نکات کلیدی

- «اپ به‌جای کتابخانه» یعنی واحد دیپلوی مسیر یا دامنه است، نه یک دکمه داخل design system.
- آماده‌کردن برای تولید بیشتر درباره کش، سازگاری، و هماهنگی release است تا درباره پلاگین Webpack.
- remoteEntry را مثل بقیه assetهای CDN مدیریت کن؛ لایه کش جدا اختراع نکن مگر مجبور شوی.
- شکست قرارداد هنوز انتشار دو مرحله‌ای می‌خواهد. استقلال تیم این واقعیت را لغو نمی‌کند.
- تجربه از پورتال B2B Wayfair است، نه از ویترین پرترافیک فروشگاه.

## برش کوتاه

> MVP را می‌شود سر هم کرد. تولید چیز دیگری است. remoteEntry یک فایل جاوااسکریپت است؛ کشش را همان‌طور می‌شکنی که بقیه assetها را. اگر قرارداد را بشکنی، باید release را دو مرحله‌ای کنی.
