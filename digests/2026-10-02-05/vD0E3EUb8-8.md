# Context Engineering vs Prompt Engineering

- **عنوان:** Context Engineering vs. Prompt Engineering: Smarter AI with RAG & Agents
- **لینک:** https://www.youtube.com/watch?v=vD0E3EUb8-8
- **کانال:** IBM Technology
- **بازدید:** ۲۵۳٬۵۱۲
- **موضوع:** prompt engineering tricks for coding agents / LLM agent tools RAG

## خلاصه

ویدیو پرامپت را از context جدا می‌کند. پرامپت‌نویسی ساختن متن ورودی است: دستور، مثال، قالب. context engineering چیدن همه‌چیزی است که مدل موقع استنتاج می‌بیند: همان پرامپت، به‌علاوه سند بازیابی‌شده، حافظه، و ابزار. مثال عامل سفر «گریم» است. «برای کنفرانس DevOps ماه بعد در پاریس هتل بگیر» به Best Western در پاریسِ کنتاکی ختم می‌شود، چون کنفرانس در پاریس فرانسه است. می‌شود گفت پرامپت مبهم بوده. می‌شود هم گفت اگر عامل تقویم یا صفحه کنفرانس را ابزار داشت، خودش مکان را درمی‌آورد. اصلاح بعدی هتل ۹۰۰ یورویی است، چون سیاست سفر شرکت در زمینه نبوده.

تکنیک‌های پرامپت: نقش («بازبین امنیت پایتون» خروجی را عوض می‌کند)، few-shot به‌جای فقط توضیح، زنجیره فکر برای مدل‌های قبل از استدلال تقویتی، و قید صریح مثل سقف صد کلمه یا «فقط از زمینه داده‌شده». اجزای context: حافظه کوتاه با خلاصه مکالمه تا پنجره پر نشود، حافظه بلند با پایگاه برداری برای ترجیح و سفر قبلی، state برای پرواز و هتل و انتقال فرودگاهی، RAG که به‌جای کل آیین‌نامه فقط بند مربوط را برمی‌گرداند، و ابزار برای SQL و قیمت زنده و دیپلوی. توضیح ابزار باید بگوید چه می‌کند، کی استفاده شود، و چه قیدی دارد. پرامپت نهایی می‌تواند حدود ۸۰ درصد محتوای پویا باشد و ۲۰ درصد دستور ثابت. جوک آخر: تأیید مدیر و مالی شش تا هشت هفته طول می‌کشد و کنفرانس دو هفته دیگر است؛ «پرامپت مدیرت را مهندسی کرده‌ای؟»

## نکات کلیدی

- پرامپت بهتر سؤال را بهتر می‌کند. context سیستم را قادر می‌کند کار را واقعاً انجام دهد.
- خطای پاریس کنتاکی هم ضعف جمله است هم غیبت ابزار. هر دو را جدا حساب کن.
- RAG یعنی برش مرتبط، نه چسباندن کل ویکی شرکت به زمینه.
- state بین گام‌ها همان چیزی است که عامل را از چت تک‌نوبتی جدا می‌کند.
- اگر ۸۰ درصد زمینه پویا است، بازنویسی جمله ثابت کم‌بازده‌ترین بهینه‌سازی است.

## برش کوتاه

> هتل در پاریس کنتاکی رزرو شد، چون کنفرانس در پاریس فرانسه بود و عامل تقویم نداشت. پرامپت جمله را درست می‌کند. context سیستم را.
