## خلاصه

ویدیو یک مرور کوتاه از به‌روزرسانی مه ۲۰۲۶ پلتفرم وب است، با دمو، نه با گزارش سازگاری مرورگرها. شبه‌کلاس `:open` برای حالت باز `details` و `dialog` را نشان می‌دهد و روی دیالوگ یک انیمیشن می‌گذارد تا باز شدن دیده شود. بعد container query فقط با نام را از نوع اندازه‌ای جدا می‌کند: روی کانتینر عمداً `container-type` اندازه نمی‌گذارد و فقط با نام، رنگ و پس‌زمینه و خط دور را scope می‌کند. ترکیب «فقط نام» با شرط اندازه در مثالی که نشان می‌دهد غلط است.

پشتیبانی جزئی و محدود lazy load بومی برای ویدیو و صوت را هم جزو همین موج می‌آورد: رسانه وقتی نزدیک دید می‌شود شروع به بار شدن می‌کند. Web Serial API و Document Picture-in-Picture در دمو هستند؛ سریال را به دستگاه‌هایی مثل micro:bit وصل می‌کند و picture-in-picture سند را جایی برای HTML جدا می‌داند. بخش آزمایشی و بتا: تزئین‌های CSS برای gap، متدهای scroll مبتنی بر Promise، و BFCache برای صفحه‌های دارای WebSocket، به‌علاوه field-sizing.

جمع‌بندی گوینده یک جهت است: جاوااسکریپت و هک کمتر، قابلیت بومی بیشتر. بازدید ویدیو خیلی کم است و سطحش آموزشی است؛ قبل از تکیه در تولید باید جدول پشتیبانی مرورگر را جدا چک کرد.

## نکات کلیدی

- `:open` انیمیشن دیالوگ و details را بدون کلاس دستی باز/بسته ممکن می‌کند.
- container query نام‌دار استایل را scope می‌کند و جایگزین کوئری اندازه نیست.
- lazy load بومی رسانه هنوز «پشتیبانی جزئی» توصیف می‌شود، نه پیش‌فرض همه‌جا.
- Web Serial و Document Picture-in-Picture APIهای تعاملی‌اند، نه جایگزین فریم‌ورک.
- جهت پلتفرم در این روایت حذف هک جاوااسکریپتی است؛ سازگاری را جدا بررسی کن.

## برش کوتاه

> کوئری کانتینرِ فقط-نام حق ندارد اندازه را هم شرط کند. ویدیو و صوت را می‌شود بومی تنبل لود کرد، ولی پشتیبانی هنوز جزئی است. مسیر پلتفرم جاوااسکریپت کمتر است.
