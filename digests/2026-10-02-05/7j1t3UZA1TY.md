# MCP vs API

- **عنوان:** MCP vs API: Simplifying AI Agent Integration with External Data
- **لینک:** https://www.youtube.com/watch?v=7j1t3UZA1TY
- **کانال:** IBM Technology
- **بازدید:** ۱٬۲۳۶٬۰۵۳
- **موضوع:** MCP tools AI agent integrations

## خلاصه

ویدیو MCP را، که آنتروپیک اواخر ۲۰۲۴ به‌صورت استاندارد باز معرفی کرد، در برابر API می‌گذارد. استعاره USB-C است: لپ‌تاپ میزبان است، پروتکل همان درگاه است، و مانیتور و دیسک و شارژر سرورهای MCP هستند که سازنده‌شان مهم نیست. معماری: میزبان چند کلاینت MCP دارد، هر کلاینت یک نشست JSON-RPC به سرور باز می‌کند، و سرور قابلیت را تبلیغ می‌کند؛ پایگاه داده، مخزن کد، یا ایمیل.

سه اولیه اصلی است. ابزار کارِ قابل فراخوانی است، مثل آب‌وهوا یا ساخت رویداد تقویم، با نام و توضیح و طرح ورودی و خروجی. منبع داده فقط‌خواندنی است: فایل، شمای پایگاه، محتوای سند. قالب پرامپت پیشنهاد آماده است. خیلی از سرورها فعلاً فقط ابزار دارند. عامل در زمان اجرا فهرست را می‌پرسد و بدون دیپلوی مجدد قابلیت جدید را می‌بیند.

REST همان مدل کلاینت-سرور روی HTTP است، با GET و POST و PUT و DELETE، و هر سرویس شکل endpoint و احراز هویت خودش را دارد. پنج API یعنی پنج آداپتور. پنج سرور MCP همان فراخوانی‌ها را می‌فهمند. تفاوت مهم کشف پویا است: REST معمولاً فهرست زنده ندارد و تغییر endpoint کار توسعه‌دهنده است. MCP برای عامل طراحی شده و فرض‌های مفید عامل را داخل پروتکل گذاشته. ضربه نهایی ویدیو این است که خیلی از سرورهای MCP زیر پوسته همان API قدیمی را صدا می‌زنند. سرور گیت‌هاب ابزار سطح‌بالا عرضه می‌کند و داخلش درخواست REST گیت‌هاب می‌سازد. پس این دو رقیب نیستند؛ لایه‌اند. MCP رابط دوستانه برای عامل است و API موتور زیرین.

## نکات کلیدی

- MCP درگاه مشترک عامل است. API قرارداد عمومی سیستم‌هاست، قدیمی‌تر از مدل زبانی.
- کشف پویا یعنی عامل بپرسد «چه کار بلدی؟» به‌جای اینکه انسان آداپتور جدید بنویسد.
- ابزار و منبع و قالب پرامپت سه اولیه هستند؛ خیلی جاها فقط ابزار پیاده شده.
- سرور MCP اغلب لفاف یک API موجود است. جایگزین کردن REST هدف نیست.
- «ما MCP داریم» اگر زیرش همان endpoint قبلی باشد، معماری جدید نیست؛ مترجم است.

## برش کوتاه

> MCP و API دشمن هم نیستند. سرور گیت‌هاب ابزار را به درخواست REST ترجمه می‌کند. یک درگاه مشترک روی همان سرویس‌هایی که از قبل داشتی.
