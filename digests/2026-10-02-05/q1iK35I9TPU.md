# Update on web platform APIs for WebAI (BlinkOn 21)

- **لینک:** https://www.youtube.com/watch?v=q1iK35I9TPU
- **کانال:** BlinkOn
- **بازدید:** ۱۷۶
- **موضوع:** web platform APIs latest 2026

## خلاصه

جلسه روز دوم BlinkOn 21 درباره APIهای هوش مصنوعی پلتفرم وب است. مایک، کنجی، رایلی و جی‌وون دو مسیر را جدا می‌کنند. Built-in AI یعنی مدل‌هایی که مرورگر و سیستم‌عامل می‌دهند و توسعه‌دهنده وب همان‌جا صدا می‌زند. WebNN یعنی چارچوب بهینه برای مدلی که خود توسعه‌دهنده می‌آورد و روی محاسبه دستگاه اجرا می‌کند. نسبت به BlinkOn قبلی، چند API از origin trial فارغ و در Chrome پایدار شده‌اند.

اول مترجم: ترجمه متن با مدل محلی، تأخیر کم، قابلیت آفلاین، و ندادن متن کاربر به سرور. دوم تشخیص زبان: زبان قطعه متن به‌همراه میزان اطمینان، سریع، و مناسب مسیریابی ورودی ناشناس به سمت ترجمه. سوم قابلیتی برای فشرده کردن متن بلند به خلاصه، تیتر، یا گلوله داخل خود مرورگر. زیرنویس خودکار این سومی را باز «translator» صدا می‌زند؛ توصیف عملکرد، خلاصه‌ساز است نه مترجم دوم. این ابهام را باید با مستند Chrome Built-in AI حل کرد، نه با اعتماد کور به کپشن.

ادامه جلسه درباره حفره‌های خواسته‌شده است. embeddings روی دستگاه، چون با prompt API ترکیب می‌شود و پایه خیلی از کاربردهاست. فراتر از متن: بهتر کردن Web Speech، تولید گفتار با مدل، و دست‌کاری و segmentation تصویر. ایده task API این است که اگر بگویی «خلاصه کن» یا «غلط بگیر»، پلتفرم مدل خبره همان کار را انتخاب کند تا روی دستگاه‌های بیشتر کیفیت و سرعت قابل قبول بماند، نه یک مدل غول همه‌کاره. دموی پایانی گفتار را محلی به متن تبدیل می‌کند و مدل همان‌جا جواب می‌دهد. افزونه Web AI برای دیدن عملکرد همین APIها روی دستگاه معرفی می‌شود.

## نکات کلیدی

- دو لایه را قاطی نکن: مدل آماده‌ی مرورگر، در برابر WebNN برای مدل خودت.
- ترجمه و تشخیص زبان به‌عنوان API پایدار Chrome در این جلسه اعلام می‌شوند؛ داده روی دستگاه می‌ماند.
- خلاصه‌سازی محلی در روایت هست، ولی نام دقیق API در زیرنویس خودکار قاطی شده است.
- embeddings روی دستگاه قطعه گم‌شده برای ترکیب با prompt API است.
- مدل خبره برای هر task راه رسیدن به دستگاه ضعیف‌تر است، نه یک مدل بزرگ برای همه.

## برش کوتاه

> مترجم و تشخیص زبان از origin trial بیرون آمده‌اند و در Chrome پایدارند. داده کاربر برای ترجمه محلی می‌ماند. embeddings روی دستگاه همان تکه‌ای است که prompt API را واقعاً کاربردی می‌کند.
