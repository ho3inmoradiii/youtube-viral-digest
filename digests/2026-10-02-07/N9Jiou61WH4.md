## خلاصه

این ویدیو رسمی تیم کروم برای DevTools در Chrome 94 است، نه اخبار ۲۰۲۶. ارزشش این است که چند عادت دیباگ را نشان می‌دهد که هنوز در کار روزمره به‌درد می‌خورند، به‌خصوص کنار container query که در موضوعات همین اجرا هم برگشته.

جسلین این‌ها را مرور می‌کند. زبان رابط DevTools: بیش از ۸۰ زبان از Settings، با مسیر گزارش ترجمهٔ غلط. شبیه‌سازی اندازهٔ Nest Hub و Nest Hub Max در device mode، به‌همراه قاب دستگاه. در پنل Application، روی فریم اصلی، بخش Origin Trials وضعیت توکن و تاریخ انقضا را نشان می‌دهد تا قبل از همگانی شدن یک API آزمایشی، تکلیفش روشن باشد. برای CSS container query یک badge کنار عنصر کانتینر آمده؛ کلیک روی آن overlay کانتینر و فرزندهایی که از آن query می‌گیرند را روشن می‌کند. در Network یک invert برای فیلتر اضافه شده: مثلاً `status-code:404` را بزنید و با invert بقیهٔ درخواست‌ها را ببینید. در Settings بخش Elements، Show rulers خط‌کش و امتداد اندازه را موقع inspect روشن می‌کند.

برای تیم فرانت، badge کانتینر و فیلتر معکوس شبکه عملی‌ترین تکه‌ها هستند. بقیه (زبان UI، دستگاه Nest، origin trial) زمینه‌اند. اگر دنبال «چه چیزی این ماه به DevTools اضافه شده» هستید، این ویدیو آن منبع نیست؛ Chrome 94 مربوط به ۲۰۲۱ است و در نتایج جست‌وجوی اخبار DevTools هنوز پرتکرارترین ویدیوی رسمی با بازدید بالاست.

## نکته‌های کلیدی

- منبع رسمی است، ولی مال Chrome 94 است نه چرخهٔ ۲۰۲۶.
- badge کانتینر، queryهای CSS را روی خود عنصر قابل دیدن می‌کند.
- فیلتر معکوس Network برای «همه‌چیز به‌جز ۴۰۴» به درد دیباگ نویز می‌خورد.
- خط‌کش Elements اندازه را بدون افزونه نشان می‌دهد.
- Origin Trials را از Application می‌شود از نظر انقضا و وضعیت توکن چک کرد.

## برش کوتاه

> «کنار عنصر کانتینر یک badge هست. با کلیک، محدودهٔ کانتینر و عنصرهایی که از اندازه‌اش query می‌گیرند روشن می‌شود.»

> «فیلتر ۴۰۴ را بزنید و invert را روشن کنید تا ببینید چه درخواست‌هایی ۴۰۴ نیستند.»
