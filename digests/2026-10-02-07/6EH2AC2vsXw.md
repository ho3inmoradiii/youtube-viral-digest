## خلاصه

ویدیو جمع‌بندی تغییرات پلتفرم وب در مه ۲۰۲۶ است و لحنش دمو محور است، نه اخبار رسمی خط‌به‌خط. چیزهایی که برجسته می‌کند: شبه‌کلاس برای حالت باز `details` و `dialog` تا انیمیشن باز شدن را بشود با CSS نوشت؛ container query فقط با نام، که عمداً sizing ندارد و فقط محدودهٔ استایل را به یک کانتینر اسم‌دار محدود می‌کند (اگر همزمان سایز بخواهید، آن شکل «فقط نام» غلط است)؛ پشتیبانی محدود و جزئی lazy loading بومی برای ویدیو و صوت، یعنی مدیا وقتی نزدیک دید می‌شود بار شود؛ Web Serial برای حرف زدن با سخت‌افزار (مثالش میکروبیت)؛ و Document Picture-in-Picture که هنوز آزمایشی است و می‌شود یک تکه HTML را در پنجرهٔ تصویر در تصویر گذاشت.

در سطل پیش‌نمایش بتا هم این‌ها را نام می‌برد: تزئین gap در CSS، متدهای اسکرول مبتنی بر Promise، رفتار bfcache برای صفحه‌هایی که WebSocket دارند، و field-sizing. پیام جمع‌بندی خودش این است که جهت پلتفرم همان است که در ویدیوهای پلتفرم دیگر هم دیده می‌شود: جاوااسکریپت و هک کمتر، قابلیت بومی بیشتر. دموها کوتاه و گاهی بریده‌اند؛ برای تصمیم تولید باید پشتیبانی واقعی مرورگر هر مورد جدا چک شود، ولی فهرست، نقشهٔ «چه چیزی از JS به CSS/HTML مهاجرت کرده» را برای مه ۲۰۲۶ می‌دهد.

## نکته‌های کلیدی

- `:open` (حالت باز details/dialog) انیمیشن را از JS به CSS می‌برد.
- container query نام‌فقط برای scope استایل است، نه برای واکنش به اندازه؛ قاطی کردن این دو باگ ذهنی رایج است.
- lazy بومی ویدیو/صوت هنوز پشتیبانی محدود دارد، ولی همان ایدهٔ «تا دیده نشد بار نکن» است.
- Web Serial و Document Picture-in-Picture قابلیت دستگاه و پنجرهٔ شناورند، نه جایگزین فریم‌ورک.
- جهت کلی مه ۲۰۲۶: بومی‌تر، هک کمتر. هر آیتم را با وضعیت مرورگر خودتان بسنجید، نه با دمو.
