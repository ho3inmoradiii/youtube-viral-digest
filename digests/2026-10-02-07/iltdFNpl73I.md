- **موضوع:** Claude Cursor Copilot agent tips

## خلاصه

Andrew، که خودش را مهندس ارشد می‌داند، ویدیو را «راهنمای ضد وایب‌کدر» برای Claude Code و Cursor معرفی می‌کند. مدل را حدس‌زن می‌بیند؛ کار انسان این است که حدس‌ها را بهتر کند. دو شیوه را مقابل هم می‌گذارد: کبوتری که فقط «ادامه بده» می‌زند و پروژه را هی رول‌بک می‌کند، در برابر استفادهٔ حساب‌شده.

اشتباه اول خودش و بقیه: نرفتن به plan mode. در کدنویسی دستی کنترل قدم‌به‌قدم بود و کمتر می‌شد مسیر را گم کرد. با AI مثل قطار است؛ سریع است و زود منحرف می‌شود. پلن مشترک، حالت‌های فکر عمیق، و رفت‌وبرگشت قبل از کد، edge case را جلو می‌اندازد و توکن را ذخیره می‌کند.

دوم: پرامپت را جایی که ممکن است دیکته کنید نه تایپ. پرامپت صوتی برای او بلندتر و مشخص‌تر از پرامپت کوتاه تایپی درآمده. (وسط ویدیو یک بخش اسپانسری n8n و VPS هست که توصیهٔ محصول است، نه تکنیک مدل.)

سوم: MCP را پورت USB برای وصل کردن مدل به دنیای واقعی می‌داند. Context7 داک به‌روز پکیج‌ها را می‌آورد، مخصوصاً جایی که آپدیت یک پکیج JS بقیه را می‌شکند. هشدار: MCP سوپابیس دسترسی زیادی به اسکیما می‌دهد و در تئوری می‌تواند دیتابیس را خراب کند؛ معاملهٔ آگاهانه است.

چهارم: با مدل مثل جونیور خیلی سریع رفتار کنید. گاهی فیچر را درست می‌زند، گاهی با اعتمادبه‌نفس پرت می‌رود. وظیفهٔ مشخص، کانتکست تنگ، راهنمایی دائمی. مدل جای خالی را پر می‌کند تا شما را راضی کند؛ شما باید آن جای خالی را دقیق کنید.

پنجم: اگر می‌ترسید مهارت کدنویسی‌تان آب شود، جلسه را pair programming ببینید. بپرسید چرا این کار را کرد. برای اپ شخصی که فقط باید دربیاید این سخت‌گیری کمتر مهم است؛ برای کسی که در شرکت کار می‌کند، سرعت شرکت را با یادگیری خودش عوض نکند.

ششم: compound engineering. هر پرامپت باید کدبیس و مدل را باهوش‌تر کند. چیزهایی که هی تکرار می‌کنید (تم، شکل کامپوننت) برود داخل CLAUDE.md و Cursor rules، مثل داک اپ. زیاده‌روی هم پنجره را منفجر می‌کند.

هفتم: اگر طراحی ضعیف است، از Mobbin اسکرین‌شات بگیرید و فقط پالت و فونت را قید کنید، وگرنه مدل نصف UI را عوض می‌کند.

## نکته‌های کلیدی

- plan mode قبل از کد؛ AI مثل قطار از مسیر خارج می‌شود.
- پرامپت صوتی اغلب زمینهٔ بیشتری از جملهٔ کوتاه تایپی دارد.
- MCP زمینه را بهتر می‌کند و سطح دسترسی‌اش خطر واقعی است.
- CLAUDE.md و rules برای حرف‌هایی است که تکرار می‌شوند، نه برای انشا.
- یادگیری را فدای سرعت تیکت شرکت نکنید؛ بپرسید چرا.
- قید طراحی را تنگ کنید: رنگ و فونت، نه «همین را بساز».

## برش کوتاه

> «مدل دارد حدس می‌زند. کار شما این است که حدس بهتر شود، نه اینکه بنویسید ادامه بده.»

> «هر چیزی را که هی تکرار می‌کنید بگذارید توی CLAUDE.md و rules. اگر زیاد شود، پنجرهٔ کانتکست می‌ترکد.»
