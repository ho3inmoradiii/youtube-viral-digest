## خلاصه

کپشن می‌گوید AnyPS5 بازی‌های PS5 را بدون شبیه‌سازی کنسول به ویندوز می‌برد. relinker فایل اجرایی را به فرمت بومی تبدیل می‌کند و کتابخانه‌های سیستمیِ دوباره پیاده‌شده لینک پویا را انجام می‌دهند. ری‌کامپایلر شیدر، شیدر PS5 را مستقیم به SPIR-V ولکان بدل می‌کند. می‌گوید یادداشت سازگاری از ۶۰ فریم روی GTX 1050 Ti خبر می‌دهد، پروژه جوان است، و ۱۱۰ issue باز دارد.

README همین اجرا جملهٔ معماری را تأیید می‌کند: relinker اجرایی را به فرمت بومی سیستم هدف تبدیل می‌کند، پیاده‌سازی کتابخانه‌های prx برای لینک پویا هست، و «No emulation or separate runtime process». ری‌کامپایلر شیدر SPIR-V تولید می‌کند و اگر با `ANYPS5_ENABLE_SPIRV_TOOLS` ساخته شود با Spirv-Tools اعتبارسنجی می‌شود. README نمی‌گوید هر شیدر PS5 مستقیم ولکان می‌شود. فقط می‌گوید SPIR-V تولید می‌شود.

۶۰ فریم در README مال یک بازی است، نه یادداشت کلی: Dreaming Sarah، پلتفرمر دوبعدی، پایدار ۶۰ فریم روی GTX 1050 Ti و i5-7500 با فرکانس ۳٫۴ گیگاهرتز. حالت پشتیبانی‌نشده یا غیرمنتظره حتماً `std::runtime_error` پرتاب می‌کند، `what()` به stderr می‌رود، و پروسه تمام می‌شود. README به `docs/dev/TechnicalDebt.md` لینک دارد. خود آن فایل این اجرا خوانده نشد.
