## خلاصه

فیلیپ اشمید ایجنت را روی لپ‌تاپ مخاطب نمی‌خواهد. می‌گوید با یک فراخوانی API، برای همان درخواست یک سندباکس ابری بالا می‌آید: کد، فایل، نصب ابزار، و ماندن محیط برای نوبت بعد. اسم محصول روی صحنه Antigravity داخل Gemini API است. می‌گوید هارنس، بک‌اند است و با خود ایجنت یکی نیست. IDE و CLI و ایجنت API می‌توانند ابزار یا system instruction متفاوت داشته باشند، ولی اگر جمینای روی این هارنس بهتر شود هر دو طرف سود می‌برند.

سند آنتی‌گراویتی، که همین اجرا خوانده شد، می‌گوید این ایجنت با Gemini 3.8 Flash ساخته شده و از همان هارنس IDE استفاده می‌کند. شناسهٔ پیش‌فرض در نمونهٔ کد `antigravity-preview-09-2026` است. این دو جمله با هم می‌خوانند، به شرطی که «همان هارنس» را «همان ایجنت» ترجمه نکنی. خود سخنران همین تفکیک را گفت.

Interactions API را جواب خودش به Responses API می‌خواند و می‌گوید برای مدل و ایجنت یک شکل فراخوانی دارد. حالت سمت سرور با دادن شناسهٔ نوبت قبل است. کار طولانی، مثل ساخت ویدیو، اتصال HTTP را باز نگه نمی‌دارد. شناسه می‌گیری و استریم یا poll می‌کنی. ابزار داخلی مثل Google Search و URL context را با تابع خودت قاطی می‌کنی. مثال کوتاهش یک ایجنت CVE برای ری‌اکت است که جست‌وجو می‌کند، صفحه را می‌خواند، و نتیجه را ساخت‌یافته برمی‌گرداند.

حرف طراحی‌اش این است که نوبت user و model برای ایجنت کم است. خروجی تابع از محیط می‌آید، نه از کاربر. برای همین به‌جای نوبت، گام می‌گذارد و نوع هر کار را جدا می‌نویسد. این اجرا صفحهٔ interactions-overview را کامل نگرفت. راهنمای quickstart فقط می‌گوید `interaction.steps` استدلال، فراخوانی ابزار، و اجرای کد را فهرست می‌کند. شکل دقیق استپ «نتیجهٔ تابع» از روی این دو متن ساخته نشد.

محیط را جدا از تاریخچهٔ حرف می‌داند. سند quickstart همین را با دو پارامتر نوشته. `previous_interaction_id` تاریخچه است. `environment` فایل و پکیج و وضعیت سندباکس است. می‌توانی شناسهٔ محیط را تنها بدهی و گفت‌وگوی تازه در همان دیسک داشته باشی، یا تاریخچه را نگه داری و `environment="remote"` یک جعبهٔ تازه بسازد. روی صحنه گفت چند ایجنت می‌توانند یک محیط را با فایل‌سیستم شریک شوند. سند، اشتراک را با استفادهٔ دوباره از شناسهٔ محیط می‌گوید، نه با یک جملهٔ جدا دربارهٔ سه ایجنت.

مهارت را filesystem-native خواند. پوشهٔ skills به system instruction می‌چسبد و `AGENTS.md` هم خودکار به همان دستور سیستم اضافه می‌شود. سند آنتی‌گراویتی مسیر را `.agents/skills/` و فایلی مثل `AGENTS.md` نوشته، نه هر اسم پوشه‌ای که روی صحنه شنیده شد. Agents API برای این است که یک محیط از قبل آماده‌شده را با یک شناسه به ایجنت بعدی بدهی، بدون Terraform و Kubernetes و Firecracker. CLI تازه‌اش را ایجنت کدنویسی نخواند. گفت ابزاری است که ایجنت کدنویسی با آن Gemini API را صدا بزند.

دمو، رادیوی گفت‌وگو داخل AI Studio است. ایجنت را «فقط فایل» دانست: یک `AGENTS.md` و skillهایی که مدل‌های دیگر جمینای را برای گفتار و موسیقی صدا می‌زنند. اولین درخواست زمین بازی را حدود ۷ تا ۱۰ ثانیه گفت تا محیط بالا بیاید. بعد از خود ایجنت خواست بگوید کجا نشسته. جوابی که برای اتاق خواند: اوبونتو، ۸ vCPU، ۱۶ گیگابایت رم، پایتون و pip. دنباله‌اش نصب بودن Node بود.

## سند، نه خودگزارش

جدول «Pricing & resources» در صفحهٔ محیط می‌گوید هر محیط CPU ثابت ۴ هسته و حافظهٔ ۱۶ گیگابایت دارد. محاسبهٔ محیط در دورهٔ پیش‌نمایش جدا صورتحساب نمی‌شود. همان صفحه، چرخه را این‌طور نوشته: بعد از ۱۵ دقیقه بی‌فعالیتی اسنپ‌شات خودکار و توقف، نگهداری آفلاین تا ۷ روز از آخرین فعالیت، بعد حذف با TTL. دادن شناسهٔ منقضی `404` برمی‌گرداند. بالا آمدن محیط تازه را «تا حدود ۵ ثانیه» نوشته و گفته ریپوی بزرگ می‌تواند این را بیشتر کند. پایین صفحه: `Last updated 2026-09-24 UTC`.

۱۶ گیگابایت حرف صحنه با جدول یکی است. ۸ هسته با ۴ هستهٔ جدول یکی نیست. ۷ تا ۱۰ ثانیهٔ دمو با «تا حدود ۵ ثانیه»ٔ پروویژن هم یکی نیست. این اجرا روی آن سندباکس `nproc` نزد. فاصله، بین جوابی است که سخنران از مدل خواند و جدولی که صفحه هنوز نشان می‌دهد. تاریخ به‌روزرسانی صفحه ۱۳ روز قبل از صحبت است، پس جدول ممکن است از جعبهٔ همان دمو عقب باشد. برای همین ۸ و ۴ را اندازهٔ قطعی ماشین نگرفتم.

راهنمای quickstart یک فشرده‌سازی زمینه حدود ۱۳۵ هزار توکن را هم نوشته. گفتار این عدد را نگفت.

جمله‌هایی که این اجرا جدا چک نشد و وارد پست نشد: «۴ سنت برای هر تصویر» برای Nano Banana Lite، عرضهٔ Omni Flash «دیروز»، آدرس شفاهی `toi.dev`، و نسخهٔ «Antigravity 2.0».

## نکته‌های کلیدی

- هارنس مشترک با IDE، در حرف خود سخنران، به‌معنی همان ایجنت نیست
- تاریخچه و دیسک دو شناسه‌اند
- مدل روی صحنه ۸ هسته و ۱۶ گیگ گفت. جدول سند ۴ هسته و ۱۶ گیگ است و صفحهٔ محیط ۹ سپتامبر ۲۰۲۶ به‌روز شده

- ایجنت دمو را خودش فقط فایل دانست: `AGENTS.md` به‌علاوهٔ skill
