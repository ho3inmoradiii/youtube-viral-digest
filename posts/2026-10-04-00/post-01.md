# یک فاصله، کش را کشت

امضای فکر را توی لاگ کپی کردیم.
یک فاصلهٔ اضافه ته خط ماند.

ایوان لئو، از تجربهٔ توسعه‌دهنده در گوگل دیپ‌مایند، دیشب روی کانال AI Engineer گفت استارتاپ‌ها با همین یک فاصله کش را از دست می‌دادند. مدل جمینای بعد از پاسخ یک رشتهٔ مات برمی‌گرداند. اسمش thought signature است. اگر همان رشته برنگردد، کیفیت دور بعد پایین می‌آید. API قدیمی از تو می‌خواست این حباب را خودت بین نوبت‌ها جابه‌جا کنی.

Interactions API به‌جایش یک interaction ID می‌دهد. نوبت بعد فقط previous interaction ID را برمی‌گردانی و زمینه سر جایش می‌ماند. عنوان صحبت را از روی مقالهٔ معروف برداشته: an interaction is all you need.

اگر امضا را با دست حمل می‌کنی، یک فرمتر کافی است تا مدل دور بعد ضعیف‌تر شود.

شناسه را برگردان. امضا را ویرایش نکن.
