# خودمیزبان، صورتحساب مدل را خط نزد

ریپو را داخل شرکت آوردیم.
متر توکن بیرون ماند.

ریل skip_ci بامداد به وقت تهران WeKnora تنسنت را آورده. کپشن یک پایگاه دانش را سه خروجی می‌داند: جست‌وجوی قابل‌استناد، ایجنتی که کار را در کانتینر سندباکس خودش جلو می‌برد، و ویکی‌ای که از همان فایل‌ها ساخته می‌شود. README ریپو همین سه را روی یک پایگاه می‌گذارد و سندباکس را Docker و E2B و Cube می‌شمارد. فروشندهٔ مدل را بیست‌وهفت تا نوشته، و Ollama هم داخل همان فهرست است. دیتابیس برداری را هشت تا اسم برده. ستاره را API گیت‌هاب همین اجرا ۳۱۹۱۴ نشان داد. کپشن ۳۱۸۰۰ نوشته بود.

ته کپشن را برنداشته: یا پول API مدل را می‌دهی، یا برای اجرای محلی GPU می‌خواهی. مسیر محلی در README هست. رایگان بودنش از خودمیزبان درنمی‌آید.

جعبه مال توست. اگر مدل را نیاورده‌ای داخل، خودمیزبان فقط جلد دانش است.

مدل را کنار همان سندها اجرا می‌کنید، یا هنوز صورتحساب API جداست؟
