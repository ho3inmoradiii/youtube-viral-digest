# پرامپت پایه را عوض نکن

اولین وسوسه این است که system prompt هارنس را مال خودت کنی.

دومینیک کوندل از تیم Codex گفت app server همان JSON-RPC است که اپ، افزونهٔ IDE، VS Code، Xcode و JetBrains را راه می‌اندازد. بازرس خودش را ساخت تا رویداد واقعی را نشان بدهد، نه پیام فرضی. گفت بیش از ۱۲۰ پیام کلاینت دارند. ورود با ChatGPT را طوری گفت که مصرف از سقف خود کاربر برود. لایسنس را Apache 2 خواند.

سفارشی‌سازی را دو جا گذاشت، نه در بازنویسی پرامپت. developer instructions را به system prompt اضافه کن. گفت پرامپت پایه را مدام میزان می‌کنند تا in distribution بماند و اگر از نو بنویسی آن کار می‌سوزد. ابزار اضافه را deferred بگذار تا با tool search پیدا شود، نه این‌که همه را بریزی داخل پنجره. مدل و شبکه و فایل مجاز را گفت می‌شود روی هر نخ جدا کرد.

باینری را هم مال خودت بفرست. اگر به CLI نصب‌شدهٔ کاربر تکیه کنی، هم شکست نسخه می‌خوری هم معلوم نیست آپدیت کرده باشد. روی ویندوز خودشان دو باینری می‌فرستند: لینوکس برای WSL، و native. برای همان نسخه گفت bindings یا JSON schema بساز، چون پروتکل بین نسخه‌ها عوض می‌شود. کلاینت Visual Basic را گفت عمدتاً یک‌شات از خود Codex درآمد.

باینری کاربر، قرارداد تو نیست.

کلاینت تو باینری خودش را باندل کرده، یا CLI نصب‌شدهٔ آدم را صدا می‌زند؟
