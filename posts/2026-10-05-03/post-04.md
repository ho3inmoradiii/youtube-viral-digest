# سازگاری‌ای که خودش می‌گوید کامل نیست

یادداشت آلفا یک لایهٔ Claude Code Mods اضافه کرده.
هدفش این نیست که بتوانی مهاجرت کنی.

نسخهٔ `dsh-v0.2.1-alpha.1` از DeepSeek Harness در ۳ اکتبر ۲۰۲۶ منتشر شده. متن انگلیسی یادداشت می‌گوید لایه آزمایشی است تا ببینند قابلیت API مودها تقریباً زیرمجموعهٔ پلاگین‌های هارنس است، نه اینکه سازگاری عملی و کامل به کاربر بدهند. ریپو MIT است. ستاره را API گیت‌هاب در همین اجرا ۲۴۳۳۹۲ گفت. خلاصهٔ ویدیویی همان روز حدود ۲۴۰ هزار گفته بود.

صفحهٔ محصول هنوز Scheduled tasks را آزمایشی نشان می‌دهد و در روایت Creator mode یک پلاگین پومودورو می‌سازد، با زمان ۵ دقیقه و ۲۴ ثانیه روی خود صفحه. در همین آلفا، وظیفهٔ زمان‌بندی را قابلیت توکار وب کرده‌اند و انتخاب بستهٔ آزمایشی قبلی را پاک می‌کنند. یادآور در حالت‌های standard و creator و PTC هست و در minimal و زیرعامل نیست.

ستاره مسیر مهاجرت نیست. اگر خود یادداشت می‌گوید زیرمجموعه است، باور همان است.
