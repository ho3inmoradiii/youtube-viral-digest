# هوک مُرد؛ ماد همان نشست ماند

اسکریپت هوک یک‌بار اجرا شد و رفت.
ماد تا آخر نشست داخل خود Claude Code نشسته بود.

آدی عثمانی ۱ اکتبر در وبلاگ Claude نوشت ماد یک فایل جاوااسکریپت یا تایپ‌اسکریپت است که داخل نشست اجرا می‌شود. از نسخهٔ ۲.۱.۲۸۷ پیش‌فرض روشن است. شکلش پلاگین است. `hooks/hooks.json` یک ماژول را نام می‌برد و ماژول با `register` روی رویداد می‌نشیند. هر قلاب سه چیز می‌گیرد: راه دسترسی به خود ابزار، خود رویداد، و `next`. زنجیره مثل میان‌افزار است. سه کار مجاز است. نگاه کنی و رد کنی. دستور را عوض کنی و نسخهٔ عوض‌شده را رد کنی. یا اصلاً رد نکنی و خودت جواب بدهی، مثلاً این فراخوان ممنوع است. هوک تنظیمات یک فرمان شل است که JSON را می‌گیرد و تمام می‌شود. ماد یک‌بار بالا می‌آید و می‌ماند. می‌تواند وضعیت نگه دارد، هر نوبت یک خط روی صفحه بکشد، و به خود Claude Code برگردد.

بعضی از قابلیت‌های خود Claude Code با همین ماد ساخته شده، از جمله خواندن AGENTS.md و قاب `/diff` کنار گفتگو. سورس‌شان با تست در ریپوی `anthropics/claude-code` زیر `mods/` است. ماژول سندباکس خودش را دارد و DOM و Node ندارد. هر چیز بیرون از ماژول از همان API رد می‌شود، و آن API به فایل و فرایند و شبکه راه دارد.

حدود ۱۹ ساعت پیش ویدیوی Prompt Engineering یک شمارندهٔ ابزار را در حافظهٔ خود فایل نگه داشت. با ذخیره، نشست باز ماد را از نو خواند و شمارنده صفر شد. راهنما می‌گوید چیزی که باید از ری‌لود جان به در ببرد در `$.state` بماند. قبل از نصب ماد غریبه، `claude plugin validate` رویدادهایی را که گوش می‌دهد و فراخوان‌هایی را که می‌زند فهرست می‌کند.

میان‌افزار را برای درخواست وب نوشته بودیم. این یکی روی ماشین تو کد شخص دیگری را اجرا می‌کند، با دسترسی فایل.

اگر یک اسکریپت شل برای بستن یک دستور کافی است، ماد ننویس. ماد را وقتی بخواه که باید وسط عمل بایستد، یادش بماند، یا چیزی را روی صفحهٔ خودت بکشد.
