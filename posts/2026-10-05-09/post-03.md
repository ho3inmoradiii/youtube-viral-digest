# تستی که بار دوم مدل نمی‌خواهد

تست را دادم به ایجنت.
بار دوم همان مسیر را دوباره از مدل پرسید. این دیگر تست نبود. دموی گران بود.

ریل skip_ci ریپوی `tester-army/e2e` را آورد. README خودش می‌گوید هدف را به زبان معمولی بنویس. مثالشان این است که workspace را به پلن Pro ارتقا بده. ایجنت اپ را تا آن‌جا می‌راند. اگر assertion بعدی همان قدم را تأیید کند، عمل‌ها ضبط می‌شوند. اجرای بعدی، تا وقتی اپ عوض نشده، هیچ صدای مدلی نمی‌زند. تستی که اصلاً قدم ایجنت ندارد، از اول مدل نمی‌خواهد.

مرورگر واقعی است. Chromium و Firefox و WebKit، و برای موبایل شبیه‌ساز. مجوز Apache-2.0. API گیت‌هاب همین اجرا ۳۴۲۴ ستاره داد و آخرین پوش را `2026-10-04T20:46:43Z` دید. کپشن ستاره نگفته بود. هزینه را هم گردن تو می‌اندازد. اشتراک، کلید، یا مدل محلی.

کپشن گفته فقط یک assertion هنوز locator دارد. README این را قانون ریپو نکرده. مثال رسمی‌اش هم `agent.act` دارد، هم assertion با `getByRole`. آن جمله را از کپشن برنداشتم.

وسوسه این است که هر شب مدل تازه را روی همان سناریو رها کنی و سبز بودنش را کیفیت بنامی. ضبط یعنی مسیر شناخته‌شده ارزان بماند. مدل را بگذار برای باری که UI واقعاً عوض شده.

اسم کار قدیمی است. record and replay. فقط این بار ضبط، مال کلیک کور نیست. مال قدمی است که مدل یک بار رفته و تست بعدی نباید برایش پول مدل بدهد.

آخرین تست ایجنتی‌ات، بار دوم هنوز به مدل زنگ می‌زند؟
