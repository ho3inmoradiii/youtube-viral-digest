# مدل را روی تله‌متری خام ننشان

ده‌ها هزار ردیف JSON را بدهی دست مدل، هم کانتکست می‌ترکد هم مرز اعتماد.

ایجنت مانیتورینگ را وصل کردیم به خروجی متریک. پرامپت شد یک دیوار JSON. یک بار عدد را قاطی کرد و خوش‌حال گزارش داد. یک بار بدتر: مسیری که به دیتابیس می‌رسید از داخل سشن مدل رد می‌شد. سندباکس نبود. یک ابزار خوش‌بین بود.

در apidays India 2026، شووا جیوتی کار از Palo Alto Networks مسئله را همین‌جا می‌گذارد. خلاصه کردن تله‌متری خام با یک مدل غیرقطعی را هم اضافه بار شناختی می‌داند و هم شکست تاب‌آوری و امنیت: توهم، باد کردن پنجرهٔ کانتکست، ورک‌فلوی شکسته. حرفش جدا کردن استدلال از رندر است. به‌جای payload خام، API ایجنتی یک میکروفرانت React قطعی برمی‌گرداند، از راه MCP و افزونهٔ Apps. دادهٔ زنده — مثال خودش ClickHouse — سمت سرور MCP می‌ماند، اعتبار دیتابیس همان‌جا حبس است، و UI داخل iframe سخت سندباکس می‌شود تا به DOM و کوکی دست نزند. همگام‌سازی زمینه با حافظهٔ ایجنت از یک کانال قابل‌ممیزی JSON-RPC و postMessage رد می‌شود.

این میکروفرانت برای رزومهٔ چند تیم مستقل نیست. فاولر آن مرز را برای دیپلوی جدا خواسته بود. این‌جا آی‌فریم مرز اعتماد است. مدل حق دیدن جدول خام را ندارد.

اگر ایجنتت به دیتای عملیاتی وصل است، خروجی ابزار را دادهٔ خام می‌گیری یا یک UI سندباکس‌شده؟
